### 新增弹框分区

**简单页**（业务参数配置类）：字段平铺即可，如编码、名称、值、类型、模块、状态、备注。

**复杂页**（规则配置类）：
1. **基础设定** — 主键维度、组织、类型、有效期等
2. **匹配条件配置** — 业务过滤维度
3. **调整比例 / 业务参数** — 页面特有配置区

## 删除按钮（默认）

1. **操作限制**：选中条数、可删状态
2. **确认弹框**：「删除后不可恢复，请确认是否删除！（共 X 条）」
3. **按钮**：取消关闭；确定执行删除
4. **确定后**：数据移除或逻辑删除，列表刷新
5. 有变更记录 Tab 时：第三列写修改类型 = 删除

---

## 简单页 · 唯一性校验（业务参数配置类）

适用于编码/主键唯一的标准维护页，无需分拨纬度、有效期限：

1. 新增/编辑确定：校验**主键编码**是否已存在 → 提示「{编码字段}已存在，请修改后重试」
2. 导入：文件内主键重复 → 整份失败；与已维护数据冲突 → 整份失败，标注行级错误

---

## 复杂页 · 唯一性 / 重复校验

适用于规则类维护页（分拨纬度 / 全国纬度分开写）：

1. 按 {匹配维度} 校验已维护数据是否有交集或包含关系
2. 有交集 → 再校验有效期限是否有交集
3. 仍有交集 → 展示「数据重复提示弹框」
   - 取消：关闭弹框，不执行操作
   - 确认：关闭所有弹框，自动查询出重复数据

---

## 终止按钮（特殊页面）

仅用于数据不可物理删除的规则/配置页（参考货量重量配置）。

1. **操作限制**：通常仅生效中/待生效可终止
2. **确认弹框**：「终止后不可撤销，请确认是否终止！（共 X 条）」
3. **确定后**：结束时间改为当前时间、状态改为终止；若有优先级则写重排规则
4. 有变更记录 Tab 时：第三列写修改类型 = 终止

---

## 导入模板

有导入时，说明列必须按「上传触发 → 导入校验 → 唯一性 → 整体成败」写；细则见 [SKILL.md](SKILL.md)「导入写法」。

**无变更记录 Tab（标准骨架）：**

```markdown
|导入|1. **上传触发**<br>    1. 点击导入按钮后获取用户本地文件，由用户手动选择，完成文件上传。模版：`{Tab名}_导入模版.xlsx`。<br>2. **导入校验**<br>    1. 校验导入文件内容是否符合**新增弹框**字段规则。<br>        1. 否：**整份文件导入失败**，自动下载失败文件，问题行提示具体失败原因。<br>        2. 是：进行**唯一性校验**。逻辑：<br>            1. 根据**{唯一键字段}**校验已维护数据（生效中、待生效）是否重复。<br>                1. 数据不重复：校验通过。<br>                2. 数据重复：根据**有效期限**与上一步校验出的重复数据的有效期限校验是否有交集。<br>                    1. 无交集：校验通过。<br>                    2. 有交集：校验不通过。<br>            2. **整体导入成功/失败规则**<br>                1. 校验范围：文件全部数据行。<br>                2. 导入判定逻辑：<br>                    1. 全部数据校验无误 → 整份文件导入成功。<br>                    2. 任一数据校验不通过 → **整份文件导入失败**，自动下载失败文件，问题行提示具体失败原因。|
|下载模版|单击下载 `{Tab名}_导入模版.xlsx`。|
```

**多维度唯一性（示例：人员 / 分拨）：** 在「是：进行唯一性校验」下分 `1. **维度=分拨**`、`2. **维度=人员**` 两支，再写 `3. **整体导入成功/失败规则**`；人员支须写清「人员集合有交集」等本页键。

**有变更记录 Tab：** 说明列同上；第三列写修改类型、有效周期等联动。

**对照样例：** `docs/百分比重量/货量重量配置.md`（分拨/全国维度）；`docs/薪资线上化/移动自动合托提成方案维护.md`（适用分拨、月额度）。

### 状态判定（有时效的规则页）

| 状态 | 判定规则 |
|------|---------|
| 生效中 | 有效期限包含当前时间 |
| 待生效 | 开始时间 > 当前时间 |
| 已失效 | 结束时间 < 当前时间 |
| 终止 | 手动终止（仅不可删数据的特殊页） |

### 有效期限惯例（规则页）

- 开始时间：日期 + 固定 `15:00:00`
- 结束时间：日期 + 固定 `14:59:59`，必须大于开始时间
