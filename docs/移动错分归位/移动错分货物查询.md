# 二、要解决的问题

V100：货物错分，装车时提示强装/错分弹窗，但是当时确实装出去了，并且已经出库，但后期撤销了，实际没                有发出去，后期还是需要移动到正确货区。

V110：1. 跟班装车网点货装车放错时，现网只提示「跟班装车货物，无法扫描」，不进入【移动错分货物查询】，现场难查、难归位。  
2. 跟班装车网点到件扫到别人的货时，没有进入【移动错分货物查询】的规则，分拨侧不好监控。  
3. 查询里分不清是普通装车错分/强装、跟班装车拦下的，还是网点到件发现的。

### V1.1.0

本版交付四块：跟班装车拦截进查询、跟班网点到件错分进查询、错分来源（查询页）、操作方式（查询页）。是否跟班装车网点沿用现网逻辑，不另写细则。未写明的现网字段与交互默认不变。奖罚报表同步字段另见后续版本，本版不展开。

#### 现网装车错分/强装进入时的错分来源

沿用 V1.0.0 进入【移动错分货物查询】的路径（装车扫描点“错分/强装”取消进入，或确认后打错分标识再撤销进入，或撤销时仍满足错分/强装判定进入）。进入后，错分来源为“装车错分/强装”。

#### 跟班装车拦截进入【移动错分货物查询】

1. 操作分拨 PDA 装车扫描时，判断是否为跟班装车网点货（现网逻辑）。
  1. 是：进行以下判断。
  2. 否：不走本路径，现网装车逻辑照旧。
2. 比较货区路由下一站与装车交接单下一站（货区路由下一站取现网已有数据）。
  1. 相等：提示：跟班装车货物，若需要装车请联系主管，走临时装挂系统扫描装车（现逻辑）
  2. 不相等：提示“跟班装车货物，无法扫描，请叫移动人员归位”（提示形态复用现网“跟班装车货物，无法扫描”），扫不下去；关提示后进入【移动错分货物查询】，错分来源为“自装装车拦截”。

#### 跟班网点到件错分进入【移动错分货物查询】

1. 网点人员到件扫描时（可能在分拨场地扫，也可能货拉回网点后再扫），无弹框，不让网点选“分拨场地 / 已拉回网点”。
2. 取该货最新操作分拨，判断到件扫描网点是否为该分拨下的跟班装车网点（现网逻辑）。
  1. 是：进行以下判断。
  2. 否：不因本路径进入【移动错分货物查询】。
3. 判断目的网点是否等于到件扫描网点，或是否为到件扫描网点的下属二级（下属二级查组织架构）。
  1. 是：不算错分，不进入【移动错分货物查询】。
  2. 否：直接进入【移动错分货物查询】，错分来源为“自装到件错分”。
4. 与跟班装车拦截各自命中都要进入，不去重。同一子单可因两次扫描形成两条，错分来源分别记“自装装车拦截”“自装到件错分”。

#### 历史数据

上线前已有数据：错分来源全部为“装车错分/强装”，操作方式全部为“PDA”（不按历史皮带机/流水线扫描回填）。

#### 错分来源（查询页）

查询条件、列表、导出同步增加错分来源；现网装车错分/强装进入查询时也写入来源（见上文）。枚举：“装车错分/强装”“自装装车拦截”“自装到件错分”。

##### 查询条件


| 名称   | 说明                                                             |
| ---- | -------------------------------------------------------------- |
| 错分来源 | 下拉。选项：全部、装车错分/强装、自装装车拦截、自装到件错分。默认全部（不参与过滤）。选具体值时按列表「错分来源」精确匹配。 |


说明：其余查询条件（运单号/子单号、扫描时间、当前分拨、是否在库、是否归位等）本版不改。
