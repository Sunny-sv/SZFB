# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|电商件数量快速增长，传统人工分拣模式操作繁琐、效率低下，分拣差错率高、作业耗时久，无法适配业务发展需求|
|V2\.0\.0|1. 皮带机操作无把枪权限控制，所有退回的皮带机版本把枪均可随意操作，存在管控漏洞。<br>2. 皮带机卸车单价高于普通卸车，存在恶意使用皮带机卸车的风险，直接增加运营成本。<br>3. 部分分拨（如睢宁分拨）无移动环节，异常操作更难被发现，成本风险隐蔽性高。|
|V3\.0\.0|下货编号从 0 起，同样「下货编号数量」下最大编号可少一位（例：下货编号数量=10 时用 0～9，不必写到 10），操作工手写编号更方便；现网按 1～N 生成，落不到 0，也达不到少一位的效果。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|电商件业务增长快，人工分拣已成为分拨作业瓶颈，需上线皮带机设备，改变分拣模式；目前已确定石家庄、漯河、睢宁、哈尔滨为首批部署分拨，后续将逐步推广至其他分拨，以解决电商件分拣难的问题。|
|V2\.0\.0|运营及管理人员反馈：当前皮带机把枪使用无限制，易出现恶意刷高单价操作、虚增成本的情况，希望对操作皮带机的把枪进行权限管控，仅授权设备可操作。|
|V3\.0\.0|业务对接：隔口（下货编号）要从 0 开始维护，这样同样「下货编号数量」下编号可少一位，操作工写起来更方便。|

# 四、需求分析

## 4\.1 需求价值

|**版本**|**需求价值**|
|---|---|
|V1\.0\.0|**效率提升:**用皮带机进行分拣，大幅提升电商件分拣速度，缩短分拨作业耗时，释放分拨产能，适配电商件业务快速增长的需求；同时降低分拣差错率，提升作业准确率。<br>**业务支撑：**为分拨产能扩张提供支撑，保障电商件业务稳定发展；为后续皮带机在更多分拨的推广落地奠定基础，形成标准化皮带机分拣作业模式。<br>**体验与合规：**减轻一线分拣人员的劳动强度，改善作业体验，提升员工满意度与稳定性；统一皮带机分拣作业标准，规范分拨作业流程，提升运营管理的规范性与可控性。|
|V2\.0\.0|1. **成本管控**从源头防止恶意使用高单价皮带机操作，避免不必要的成本虚增，尤其保障无移动环节分拨的成本安全。<br>2. **风险防范**通过把枪权限控制，规范操作行为，降低人为违规、恶意操作带来的运营风险。<br>3. **管理规范**实现皮带机操作权限可配置、可管控，操作行为可追溯，提升分拨设备与作业管理精细化程度。<br>4. **数据真实**保证皮带机操作与薪资计算真实合规，避免因违规操作导致数据失真、核算异常。|
|V3\.0\.0|同样「下货编号数量」下最大编号少一位，操作工手写更方便；【皮带机下货口管理】、【皮带机分拣方案】可使用 0 号下货编号。|
