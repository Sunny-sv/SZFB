# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|电商件数量快速增长，传统人工分拣模式操作繁琐、效率低下，分拣差错率高、作业耗时久，无法适配业务发展需求|
|V2\.0\.0<br>|1. 皮带机操作无把枪权限控制，所有退回的皮带机版本把枪均可随意操作，存在管控漏洞。<br>2. 皮带机卸车单价高于普通卸车，存在恶意使用皮带机卸车的风险，直接增加运营成本。<br>3. 部分分拨（如睢宁分拨）无移动环节，异常操作更难被发现，成本风险隐蔽性高。|
|V3\.0\.0|1. **提成核算无差异化，激励机制失效**：皮带机全环节提成采用统一计算规则、全员平分的模式，未区分卸车、码货、移动不同作业环节的劳动强度、作业难度与工作量，无法体现多劳多得，易打击作业积极性，引发作业推诿、效率低下等问题。<br>2. **货量归属模糊，统计数据失真**：当前皮带机作业仅统计固定卸车总货量，卸车、码货、移动全环节作业人员统一平分货量，无法精准匹配不同岗位的实际作业量，货量归属不清晰。<br>3. **环节数据无法拆分，运营管理无依据**：无分环节的货量与提成明细数据，运营侧无法精准管控各作业环节效率、核算单环节运营成本，也无法针对性开展流程优化与人员管理。|
|V4\.0\.0|【皮带机操作货量】要按扫描当时的路由下一站、货区、皮带机、下货编号汇总与导出；若扫描不落数，报表只能查最新方案，历史对不上。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|电商件业务增长快，人工分拣已成为分拨作业瓶颈，需上线皮带机设备，改变分拣模式；目前已确定石家庄、漯河、睢宁、哈尔滨为首批部署分拨，后续将逐步推广至其他分拨，以解决电商件分拣难的问题。|
|V2\.0\.0|运营及管理人员反馈：当前皮带机把枪使用无限制，易出现恶意刷高单价操作、虚增成本的情况，希望对操作皮带机的把枪进行权限管控，仅授权设备可操作。|
|V3\.0\.0|皮带机卸车、码货、移动各环节的作业量、劳动强度差异显著，当前货量与提成全员平分的模式无法匹配个人实际作业贡献，有失公平；核心诉求为**将皮带机货量按卸车、码货、移动三个环节拆分，精准归属至对应作业人员；同时提成按三个环节分别设置规则、独立计算**，匹配各岗位作业特性。|
|V4\.0\.0|与【皮带机操作货量】改版对接：路由下一站、货区要以扫描当时为准，不要查最新。|

## 3.2  产品方案

|**版本**|**方案**|
|---|---|
|V4\.0\.0|皮带机扫描成功上传货量时，把皮带机编号、下货编号、路由下一站、分拣方案、目的分拨、货区编号、SN码、货量类型、体积写入货量明细；写入后不随方案/货区维护变更而改。|

# 四、需求分析

## 4\.1 需求价值

|**版本**|**需求价值**|
|---|---|
|V1\.0\.0|**效率提升:**用皮带机进行分拣，大幅提升电商件分拣速度，缩短分拨作业耗时，释放分拨产能，适配电商件业务快速增长的需求；同时降低分拣差错率，提升作业准确率。<br>**业务支撑：**为分拨产能扩张提供支撑，保障电商件业务稳定发展；为后续皮带机在更多分拨的推广落地奠定基础，形成标准化皮带机分拣作业模式。<br>**体验与合规：**减轻一线分拣人员的劳动强度，改善作业体验，提升员工满意度与稳定性；统一皮带机分拣作业标准，规范分拨作业流程，提升运营管理的规范性与可控性。|
|V2\.0\.0|1. **成本管控**从源头防止恶意使用高单价皮带机操作，避免不必要的成本虚增，尤其保障无移动环节分拨的成本安全。<br>2. **风险防范**通过把枪权限控制，规范操作行为，降低人为违规、恶意操作带来的运营风险。<br>3. **管理规范**实现皮带机操作权限可配置、可管控，操作行为可追溯，提升分拨设备与作业管理精细化程度。<br>4. **数据真实**保证皮带机操作与薪资计算真实合规，避免因违规操作导致数据失真、核算异常。|
|V3\.0\.0|1. **激励公平化，提升作业积极性**通过分环节货量精准归属、提成差异化独立计算，匹配不同岗位的实际作业贡献，真正实现多劳多得，有效激发一线作业人员积极性，减少作业推诿。<br>2. **数据精准化，保障核算准确性**拆分卸车、码货、移动各环节货量，实现作业量精准统计、归属清晰，保障出勤判定、薪资核算的准确性，减少人工核对与数据调整成本。<br>3. **管理精细化，提升运营管控能力**可获取各环节独立的作业与成本数据，支撑分拨精准管控各环节作业效率、核算单环节运营成本，针对性开展流程优化与人员管理。<br>4. **规则标准化，适配作业场景**支持按不同作业环节设置独立的提成计算规则，贴合皮带机全流程作业特性，实现薪资规则与作业场景的精准适配，提升分拨管理规范性。|
|V4\.0\.0|支撑【皮带机操作货量】按下货编号、路由下一站汇总与历史核对；扫描当时数据可追溯。|

### V2\.0\.0

1. **皮带机扫描功能入口展示校验**

    1. 把枪登录后，先校验登录员工是否拥有**皮带机扫描功能权限**：

        - 无权限：不展示皮带机扫描功能入口。

        - 有权限：继续根据**分拨中心、SN 码**校验【皮带机设备维护 \- 把枪维护】是否已配置数据。

    2. 设备维护校验：

        - 未维护数据：不展示皮带机扫描功能入口。

        - 已维护数据：正常展示皮带机扫描功能入口。

### V3\.0\.0

扫描成功生成货量时，**同步生成卸车、码货、移动三份独立货量数据**：

1. **卸车货量**

    - 货量归属人：PDA 登录人

    - 操作结算重量：按实时卸车计泡计算

2. **码货货量**

    - 货量归属人：根据分拨中心、皮带机编号、子单对应下货口编号，匹配【皮带机下货口管理】中的码货人；未维护则为空

    - 操作结算重量：按实时卸车计泡计算

3. **移动货量**

    - 货量归属人：根据分拨中心、皮带机编号、子单对应下货口编号，匹配【皮带机下货口管理】中的移动人；未维护则为空

    - 操作结算重量：按实时移动计泡计算

### V4.0.0

货量生成（卸车/码货/移动三份）规则沿用现网。本版仅补充**子单落数字段**。

#### 货量落数

扫描成功且正常上传货量时（拦截、改单仍不上传，沿用现网），在货量明细上写入下列字段：

|字段|说明|
|---|---|
|皮带机编号|本次扫描绑定的皮带机。|
|下货编号|本次匹配到的下货编号。|
|路由下一站|货区路由的**路由下一站**。|
|分拣方案|当时匹配到的方案名称。|
|目的分拨|货区路由的目的分拨（按当时货区路由写入）。|
|货区编号|按本单路由下一站查【分拨货区维护】**当时**结果写入。|
|SN码|扫描子单的把枪 SN。|
|货量类型|与现网操作货量货量类型一致。|
|体积|子单体积，单位 m³。|

写入后不随方案/货区维护变更而改。

#### 验收要点

|序号|验收要点|
|---|---|
|1|皮带机扫描成功后，货量明细可查到上表字段且有值（匹配失败为空的除外）。|
|2|事后改【皮带机分拣方案】或【分拨货区维护】，已扫子单的路由下一站、货区编号不变。|
|3|新扫描按变更后的方案/货区写入新值。|
|4|卸/码/移三份货量上的皮带机编号、下货编号、货量类型、体积等与扫描当时一致。|
