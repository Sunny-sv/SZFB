# VIP操作补贴自动录入对接记录

> 整理日期：2026-07-21  
> 需求负责人：胡绵飞  
> 对应 PRD：[奖罚处理.md](../奖罚处理.md) V1.1.12

## 对接诉求

1. 运营现从系统导出 VIP 货量，乘单价后在【奖罚处理】手动录入「发放转运质量奖金-VIP操作补贴」；希望改为系统自动录入。
2. 分配逻辑已自动，本期只改录入，不改分配规则。
3. 计算按吨：装卸补贴、移动补贴单价全国统一，用系统参数配置，不做单独维护页。

## 已确认结论

| 项 | 结论 |
| --- | --- |
| 奖罚类型 | 发放转运质量奖金-VIP操作补贴 |
| 货量来源 | 【VIP操作货量查询】人员汇总的总操作货量(吨)；【VIP移动货量查询】人员汇总的总移动货量(吨) |
| 人员对齐 | 分拨中心 + 人事工号；只在一表有数时，另一表吨数按 0 |
| 金额 | 总操作货量 × 装卸单价 + 总移动货量 × 移动单价；合成一条凭证；金额为 0 不录 |
| 岗位过滤 | 仅武职可录：装卸工、装卸组长、电叉司机、叉车组长、L卸货员、L卸货组长、L码货员、L码货组长、L电叉司机、L叉车组长、机叉司机；其余岗位不录 |
| 单价 | 系统参数：装卸默认 2 元/吨，移动默认 1 元/吨；无业务维护页 |
| 定时 | 每月 3 号 16:00 |
| 货量时间窗 | 上月 1 号 15:00 ～ 当月 1 号 14:59:59 |
| 发生时间 | 固定上月 1 号 |
| 奖罚凭证 | 人事工号 |
| 数据来源 | 系统导入 |
| 备注 | `{月}月VIP操作补贴`，例：`6月VIP操作补贴` |
| 责任人 | 该人事工号；分配金额 = 发放金额；录入后走现网自动处理 |
| 重刷 | 不做 |
| 手工录入 | 不做限制（不禁止继续手工录） |

## 人员汇总取数字段（现网截图）

**VIP操作货量查询 — 人员汇总：** 分拨中心、员工姓名、人事工号、员工状态、岗位、总操作货量(吨)

**VIP移动货量查询 — 人员汇总：** 分拨中心、员工姓名、人事工号、员工状态、岗位、总移动货量(吨)

## 备注

1. **自动防重**：同类型 + 人事工号 + 发生时间 + 分拨已存在（含手工已录）则不再自动录。
2. **手工不拦**：自动已录过同一键时，人工仍可再录，系统不提示、不拦截；可能重复计发，由业务自行控制。
3. 同一人事工号在不同分拨可各录一条，奖罚凭证相同允许并存。
4. 发放金额四舍五入保留两位小数。
5. 仅上述武职岗位自动录奖励；其余岗位不录。
6. 详细规则见奖罚处理 PRD V1.1.12。
