# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|目前，用户在操作结算重量计泡方面遇到的挑战是系统无法支持按照特定的分拨中心、具体的操作环节，甚至细化到寄件人的层级来进行维护。这导致了在实际操作中缺乏灵活性，无法针对不同的情况进行精准的成本控制。|
|V2\.0\.0|当前操作结算重量计算完成后，缺少灵活的百分比配置减免/增加机制。运营成本部无法根据业务策略对操作结算重量进行差异化调整，所有货量统一按原始计泡计算，缺乏弹性运营能力。|
|V2\.1\.0|特殊维护「调整比例」将计算类型（按票/按件/按子托）与区间类型（重量段/体积段）绑定，无法表达跨粒度组合条件。例如：无法配置「运单操作结算重量 ≥800kg 且 运单总件数 ≥50 件」才套用单独调整比例；亦无法在同一方案内同时约束票级重量与子单级重量。运营特例规则配置能力不足。|
|V2\.2\.0|全国层方案不区分操作分拨网点性质，非公司直营分拨也会命中同一套全国调整比例，与维护侧「适用分拨」圈定范围无法对齐。|
|V2\.3\.0|1. **货量重量百分比规则与特殊单价存在重复计算风险：**同一票货物扫描，若同时命中【货量重量配置】的百分比调整规则和【特殊类单价维护】补贴规则，薪资计算会出现重复加减，导致成本失控。当前计算链路缺少互斥控制逻辑，未做 “命中货量重量规则后是否允许再触发特殊单价” 的拦截，两套规则存在并行生效的可能。<br>2. **计算侧匹配逻辑与配置维护侧字段不同步：**货量重量配置】V1\.3\.0 版本维护界面已支持配置操作人、任务属性、车型、无任务交接单、周转箱内货物、时间区间、上 / 下一站所属分拨、所属省区等多类条件，但薪资计算侧依旧沿用旧版字段做匹配判断，造成后台配置完成后实际无法命中生效，也导致依赖该命中结果的控制闸门输出结果不可信。<br>3. **时间段类特殊规则无法落地生效：**业务要求依据货物扫描时间（支持跨天场景，例如 22:00‑06:00）执行差异化的货量调整比例，现有计算逻辑暂不支持按时间区间做规则命中。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|用户希望系统能够提供更加灵活和精细化的管理方式，即允许根据不同的分拨中心、操作环节，乃至寄件人来分别设置和调整操作结算重量计泡规则。这种需求的根本目的在于实现更精确的成本管理和优化，以适应不同场景下的业务需求，最终达到降低成本的目标。|
|V2\.0\.0|基于运营成本部实际业务场景：在操作结算重量计算完成后的链路中，增加一层可配置的百分比调整引擎，通过多维度规则匹配的方式，实现对货量重量的灵活上调或减免。|
|V2\.1\.0|在特殊维护 Tab 将调整比例升级为区间维度矩阵：支持票/子托/件 × 重量/体积/件数共 9 项维度任意多选组合；同一配置行内多维度 AND 命中后取该行调整比例。允许间断区间（仅维护关心档位），未覆盖货量不命中本方案、继续走方案层级兜底。统一维护 Tab 本期仍仅「不区分」，不做区间配置。|
|V2\.2\.0|运营成本部：非直营分拨中心、非直营集配站、智运分拨中心不是公司直营，扫描时不应再套旧全国方案；计算侧须按操作分拨网点性质过滤全国方案。|
|V2\.3\.0|1. **规则叠加控制逻辑：** 操作成本部明确两套规则不能默认重复叠加。开关「货量重量是否叠加」配在【特殊类单价维护】：子单已命中货量方案时，为「否」的特殊方案跳过，为「是」的仍可计算；未命中货量方案时不看该开关。<br>2. **匹配条件对齐要求：**维护侧已迭代至 V1\.3\.0 版本，计算侧需要和维护侧使用完全同一套字段进行规则命中判断，保障命中结果准确可信。|

## 3\.2  产品方案

|**版本**|**调研结果**|
|---|---|
|V2\.2\.0|全国层（特殊\-全国、统一\-全国）匹配前，先按方案「适用分拨」过滤：操作分拨网点性质须落在适用分拨内，否则本条不算候选；四层顺序、任务类型、区间命中、百分比公式沿用现网。|
|V2\.3\.0|1. **规则对齐与计算控制逻辑：**特殊维护的匹配条件、区间维度基于【货量重量配置】V1\.3\.0 做增量对齐<br>    1. 新增字段统一以扫描取值作为校验依据；<br>    2. 上 / 下一站、开单先按类型计算覆盖范围，再执行匹配比对；<br>    3. 寄件人、物品名称、包装类型为多组条件，满足任意一组即可命中；<br>    4. 时间段与配置行逻辑为 AND 关系，支持跨天时间区间。<br>2. **货量重量是否叠加：**<br>    1\. 字段在【特殊类单价维护】，不参与特殊方案排序，不计入匹配条件数量。<br>    2\. 百分比重量匹配结束后，仍按现网优先级匹配特殊方案。<br>    3\. 子单已命中【货量重量配置】：命中方案为「否」则本条不算，继续下一条；为「是」则按该条计算。能命中的全是「否」则不算特殊单价。<br>    4\. 子单未命中【货量重量配置】：不看该字段，按命中的特殊方案计算。|

# 四、需求分析

## 4\.1 需求价值

|**版本**|**需求价值**|
|---|---|
|V1\.0\.0|1. **精准成本控制：**通过支持不同层级的计泡规则设置，企业可以更精确地反映各分拨中心及操作环节的真实成本，从而制定更为合理的定价策略和服务条款，确保成本与收益的平衡。<br>2. **灵活性增强：**允许针对不同业务场景定制化管理，有助于快速响应市场变化和客户需求，提供更具竞争力的服务，同时也能适应内部流程调整或外部要求的变化。<br>3. **成本优化：**细化到寄件人级别的管理可以帮助识别高成本的操作点，并采取针对性措施减少不必要的开支。例如，鼓励寄件人优化包裹尺寸以降低体积重量，进而减少运输费用。|
|V2\.0\.0|1. 提升结算灵活性：支持按线路、产品类型等多维度对操作结算重量进行差异化调整，满足运营策略需要。<br>2. 减少人工干预：规则引擎自动匹配，无需人工调整<br>3. 策略可追溯：变更记录留痕，所有调整规则有据可查<br>4. 分拨中心自治：各分拨中心独立维护规则，互不干扰|
|V2\.1\.0|1. 组合条件可配：支持票重量\+票件数、票重量\+件重量等跨粒度组合，满足大单多件等特例场景。<br>2. 配置更贴近业务：允许只维护关心区间（如 ≥800kg 且 ≥50 件），无需铺全 0～∞ 。<br>3. 与计算逻辑对齐：区间维度与《操作结算重量计算逻辑》V2\.0\.1 百分比重量匹配口径一致，减少配置与生效偏差。<br>4. 可追溯增强：落库方案 ID，变更对比展示完整配置行表格。|
|V2\.2\.0|1. 全国方案只对勾选网点性质的操作分拨生效，避免非直营等分拨误套。<br>2. 与货量重量配置「适用分拨」同一口径，减少配置与扫描结果偏差。|
|V2\.3\.0|1. **规避成本重算风险：**已按货量百分比调过重量的单，默认不再叠特殊补贴。<br>2. **支持精细化叠加配置：**只对需要同时计取的方案生效，不必放开全部特殊方案。<br>3. **配置与算薪一致，减少对账偏差：**维护页配的条件在扫描时按同一套规则生效，避免配了却不算。|

#### 配置行命中规则

##### 区间模式 = 不区分

直接取方案上的轻实重调整、自有调整、外包调整，再按岗位取对应比例（外包工取外包调整，其他岗位取自有调整），按原百分比重量公式计算。

##### 区间模式 = 按区间配置

###### 第一步：取维度和扫描实际值

读维护页勾选的区间维度，取对应扫描实际值。

###### 第二步：检查能否匹配本方案

1. 已勾选的**每一个**维度，扫描时都必须能取到实际值。

2. 任一维度取不到数（为空、无效、系统算不出）→ **放弃本方案**，去下一层继续找。

3. **禁止**：某个维度没取到数就跳过该维度、只核对其余项，或当成「这一项不限制」仍判定命中。

> **举例**：方案勾选了「票\-操作结算重量段 \+ 票\-件数段」。扫描时运单操作结算重量能取到，但运单总件数取不到 → 本方案**直接不适用**。
> 
> 

###### 第三步：在配置行中找命中行

1. 方案下可维护多行配置；每行对已勾选维度分别维护下限～上限。

2. **同一行内须全部满足（AND）**：每个维度的实际值都须落在该行对应区间内，该行才算命中。

3. 区间判定：下限 ≤ 实际值 \< 上限。

###### **第四步：按命中结果处理**

|**命中情况**|**处理方式**|
|---|---|
|命中 **1 行**|取该行的轻实重/自有/外包调整 → 按岗位取对应比例 → 算百分比重量|
|**0 行**命中|本方案区间未覆盖本批货（间断区间属正常）→ **放弃本方案**，继续下一层|
|**多行**同时命中|配置侧应已禁止行间重叠；若运行时仍出现 → 取「各启用维度上限加总最小」的行|

**整链路兜底**：特殊维护\-分拨、特殊维护\-全国、统一维护\-分拨、统一维护\-全国四层均无有效命中 → 百分比重量 = 子单操作结算重量（无调整）。

###### 业务示例

**配置（特殊维护 · 按区间配置）**

|**票\-操作结算重量段**|**票\-件数段**|**自有调整**|**外包调整**|
|---|---|---|---|
|800～99999\.99|50～999999|\-3%|\-5%|

**命中**：运单操作结算重量 = 900kg，运单总件数 = 60 件。

1. 900 落在 800～99999\.99 内，60 落在 50～999999 内 → 均满足 → 命中该行；

2. 扫描人为自有岗位 → 取 \-3%；

3. 按该行轻实重调整及原百分比重量公式计算。

### V2\.2\.0

适用：操作分拨网点性质为直营分拨中心、服务站、直营集配站、非直营分拨中心、非直营集配站、智运分拨中心时，可按全国方案「适用分拨」判断能否命中。

#### 全国层适用分拨过滤

进入**特殊维护\-全国**或**统一维护\-全国**时，在现有公共条件（操作类型、有效期限包含扫描时间、状态不为终止）之外，增加：

1. 取**扫描发生的操作分拨**网点性质（不取上/下一站）。

2. 该网点性质须落在方案「适用分拨」内；否则本条不算候选，继续同层下一条。

3. 该层筛完没有候选或均未命中 → 进入下一层。

4. 四层均无有效命中 → 百分比重量 = 子单操作结算重量（无调整）。

**适用分拨不计入**匹配条件数量。

任务类型、四层顺序、区间命中、百分比公式沿用现网，本版不改。

已算完的扫描不因本版自动重算，仅新扫描生效。

维护页枚举、必填、导入、列表规则见【货量重量配置】，本文不重复。
