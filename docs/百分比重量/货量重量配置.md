# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|当前操作结算重量计算完成后，缺少灵活的百分比配置减免/增加机制。运营成本部无法根据业务策略对操作结算重量进行差异化调整，所有货量统一按原始计泡计算，缺乏弹性运营能力。|
|V1\.1\.0|V1\.0\.0 特殊维护「调整比例」将计算类型（按票/按件/按子托）与区间类型（重量段/体积段）绑定，无法表达跨粒度组合条件。例如：无法配置「运单操作结算重量 ≥800kg 且 运单总件数 ≥50 件」才套用单独调整比例；亦无法在同一方案内同时约束票级重量与子单级重量。运营特例规则配置能力不足。|
|V1\.2\.0|全国纬度方案不限操作分拨网点性质，非公司直营的非直营分拨中心、非直营集配站、智运分拨中心也会套上同一套全国调整比例，无法按分拨性质分开控制。|
|V1\.3\.0|1. **货量打折与特殊单价可能双命中。** 同一票既命中【货量重量配置】百分比调整，又命中【特殊类单价维护】补贴价，薪资侧重复加减，成本不可控。<br>2. **两侧匹配条件不一致。** 特殊单价能配操作人、任务属性、车型、无任务交接单、周转箱内货物、按时间段、上一站/下一站所属分拨等，货量侧配不全，无法按同一套业务口径对齐维护与重叠提醒。<br>3. **维护时看不到对侧重叠。** 录方案时不知道是否与【特殊类单价维护】可能同覆盖，只能事后对账。|

# 三、产品分析

## 3\.1  用户调研

|**版本**|产品方案|
|---|---|
|V1\.2\.0|运营成本部：非直营分拨中心、非直营集配站、智运分拨中心不是公司直营，旧全国方案不应再套这三类；全国方案需能勾选适用的分拨网点性质。|
|V1\.3\.0|1. **对接会议（2026\.10\.8，百分比重量及特殊单价业务对接确认）：** 操作成本部明确两套规则不能默认重复叠加；希望货量优先，需要时再主动允许叠加特殊单价。<br>2. **期望能力：** 两侧匹配条件对齐；有重叠时提醒，仍允许确认后保存；导入遇重叠整份继续或整份取消。|

## 3\.2  产品方案

|**版本**|产品方案|
|---|---|
|V1\.0\.0|基于运营成本部实际业务场景：在操作结算重量计算完成后的链路中，增加一层可配置的百分比调整引擎，通过多维度规则匹配的方式，实现对货量重量的灵活上调或减免。|
|V1\.1\.0|在特殊维护 Tab 将调整比例升级为区间维度矩阵：支持票/子托/件 × 重量/体积/件数共 9 项维度任意多选组合；同一配置行内多维度 AND 命中后取该行调整比例。允许间断区间（仅维护关心档位），未覆盖货量不命中本方案、继续走方案层级兜底。统一维护 Tab 本期仍仅「不区分」，不做区间配置。|
|V1\.2\.0|全国纬度增加「适用分拨」（多选）：直营分拨中心、服务站、直营集配站、非直营分拨中心、非直营集配站、智运分拨中心；仅勾选类型内的操作分拨可套用该全国方案。分拨纬度不加该字段。已有全国方案适用分拨改为直营分拨中心、服务站、直营集配站。|
|V1\.3\.0|1. **特殊维护**补齐匹配条件并集（操作人、任务属性、车型、无任务交接单、周转箱内货物；上一站/下一站补所属分拨、省区改名所属省区；开单改开单所属分拨/开单所属省区；寄件人支持等于/包含且可多填；区间维度增加按时间段）。<br>2. **新增/编辑、导入**与【特殊类单价维护】做重叠提醒（新增/编辑含区间比对，导入不含区间比对）；确认后仍可保存/整份继续导入。<br>3. **字段改名：**纬度→维度；开始时间/结束时间→生效开始时间/生效结束时间（含批量编辑生效结束时间）。|

# 四、需求分析

## 4\.1 需求价值

|**版本**|**需求价值**|
|---|---|
|V1\.0\.0|1. 提升结算灵活性：支持按线路、产品类型等多维度对操作结算重量进行差异化调整，满足运营策略需要。<br>2. 减少人工干预：规则引擎自动匹配，无需人工调整<br>3. 策略可追溯：变更记录留痕，所有调整规则有据可查<br>4. 分拨中心自治：各分拨中心独立维护规则，互不干扰|
|V1\.1\.0|1\. 组合条件可配：支持票重量\+票件数、票重量\+件重量等跨粒度组合，满足大单多件等特例场景。<br>2\. 配置更贴近业务：允许只维护关心区间（如 ≥800kg 且 ≥50 件），无需铺全 0～∞ 。<br>3\. 与计算逻辑对齐：区间维度与《操作结算重量计算逻辑》V2\.0\.1 百分比重量匹配口径一致，减少配置与生效偏差。<br>4\. 可追溯增强：落库方案 ID ，变更对比展示完整配置行表格。|
|V1\.2\.0<br>|1. 全国方案可按操作分拨网点性质圈定适用范围，直营与非直营可分开配。<br>2. 不必为同一策略按仓复制成数百条分拨方案。<br>3. 与计算侧全国层过滤口径一致，减少配错、套错。|
|V1\.3\.0|1. **两侧条件对齐：** 特殊维护可配齐与单价侧并集字段，重叠提醒更可对上。<br>2. **维护可感知风险：** 保存/导入前看到对侧重叠，减少事后扯皮。|
