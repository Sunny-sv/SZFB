# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V2\.2\.0|1. 增加车型配置：因河北电商中心货物操作难度大，并且外请任务会有箱车、平板车，其中平板车操作难度比箱车操作难度更大，补贴价格会比箱车高。<br>2. 增加无任务交接单配置：目前剔除了无任务操作的货量不计入特殊货量，但某些特定情况下需要加上无任务操作货量，否则与移动作业报表数据对不上\(例如分拨所有移动全部补贴1元\)|
|V2\.3\.0|1. **与货量方案可能双命中。** 同一票既命中【货量重量配置】百分比调整，又命中本页特殊单价，薪资重复加减。<br>2. **两侧匹配条件不一致。** 现网缺重/抛货、任务类型、是否电商件、操作人、任务属性、车型、无任务交接单、周转箱内货物及上/下一站所属分拨、所属省区等，无法与货量侧对齐维护与重叠提醒。<br>3. **区间与货量侧口径不一。** 现网计算类型 \+ 公斤段/体积段与货量侧票/子托/件维度不一致，难以做区间级重叠比对。<br>4. **维护时看不到对侧重叠。** 录方案时不知道是否与【货量重量配置】可能同覆盖。|

# 四、需求分析

## 4\.1 需求价值

|**版本**|**需求价值**|
|---|---|
|V2\.2\.0|1. 减少人工计算成本。<br>2. 增加系统灵活性。|
|V2\.3\.0|1. **规避成本重算风险**：同一票货物命中货量百分比重量调整后，默认不叠加特殊补贴，防止两套规则同时生效造成薪资重复加减，控制操作成本。<br>2. **支持精细化叠加配置**：仅对需要同时计取特殊单价的业务方案单独开启叠加开关，无需全量放开特殊方案，兼顾风控与业务灵活性。<br>3. **前置冲突预警，降低对账成本**：新增 / 编辑 / 导入方案时，提前校验与货量方案的覆盖重叠并提醒，减少发薪后薪资差异、事后对账扯皮。<br>4. **计价模型贴合现场作业**：支持区分自有 / 外包、吨价 / 托价四价配置；夜班、大票、重抛货等不同作业难度场景可直接配置对应补贴，减少线下人工补差。|
