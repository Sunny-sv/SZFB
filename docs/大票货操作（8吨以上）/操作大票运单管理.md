# 三、业务分析

## 3.1 用户调研

| 版本 | 用户调研 |
| --- | --- |
| V1.0.0 | 1. 要能按全国配，并指定哪些分拨类型生效，避免把每个分拨都维护一遍。<br>2. 个别分拨要单独改门槛，或剔掉下面某些网点。<br>3. 个别网点也要能单独配。<br>4. 重量看开单结算重量，要大于等于所配吨数；件数要落在下限和上限之间。<br>5. 要能按运单查操作大票，看得到提货方式、送货方式、到车和卸出。<br>6. 中心自提已到车、还没卸的，要在列表上能看出来。<br>7. 目的分拨文员可以在电脑上卸出，并通知客户来提；这次卸出不计货量。 |

## 3.2 产品方案

| 版本 | 产品方案 |
| --- | --- |
| V1.0.0 | 新增【操作大票运单管理】，含维护、运单列表。维护按全国、分拨、网点配置开单门槛。运单列表可查操作大票运单；目的分拨对已到车未卸出的中心自提可「卸出并通知」：电脑只写卸车轨迹（计仓储费）、不计货量、不写库存；操作工再用 PDA 卸出时写库存等其余数据并计货量、不重复写轨迹。短信与 PDA 共用。改单后不再是操作大票的仍留在列表。进表与改单刷新写清业务效果，具体执行评审跟开发定。适用：直营分拨、非直营分拨、服务站、直营集配站、非直营集配站、智运中心、航空转运枢纽。不适用：无。 |

命中顺序：该开单网点有网点行，按网点行；否则该开单网点所属分拨有分拨行，按分拨行；否则该分拨类型有全国行，按全国行；都没有，不走操作大票。

##### 按钮操作

| 名称 | 说明 |
| --- | --- |
| 新增 | 1. 不勾选也可点。打开新增弹框。<br>2. **配置范围**<br>    1. **控件：**单选下拉框；**枚举项：**全国、分拨、网点；**默认值：**总部为全国，非总部为分拨；必填。<br>    2. 非总部不展示「全国」，也不能改已有全国行。<br>    3. 切换后，下面字段按范围显示，已填内容清空。<br>3. **分拨类型**（仅配置范围=全国时显示）<br>    1. **控件：**复选框；**枚举项：**直营分拨、非直营分拨、服务站、直营集配站、非直营集配站、智运中心、航空转运枢纽；**默认值：**均不勾选；必填，至少勾 1 项。<br>4. **开单网点/分拨**（配置范围=全国时不显示）<br>    1. **配置范围=分拨：**<br>        1. **控件：**分拨中心组件，单选；**可输入范围：**直营分拨、非直营分拨、服务站、直营集配站、非直营集配站、智运中心、航空转运枢纽；**默认值：**空；必填。<br>        2. 选定后带出分拨类型，不可改。<br>    2. **配置范围=网点：**<br>        1. **控件：**分拨中心组件，单选；**可输入范围：**网点；**默认值：**空；必填。<br>5. **重量阈值（吨）≥**<br>    1. **控件：**数字输入框；**最大输入：**三位整数+两位小数；**默认值：**空；必填；须大于 0。<br>    2. 比较的是开单结算重量，开单结算重量 ≥ 所填吨数才达标。<br>6. **件数下限 ≥**<br>    1. **控件：**数字输入框；**默认值：**空；必填；正整数。<br>7. **件数上限 ≤**<br>    1. **控件：**数字输入框；**默认值：**空；必填；正整数。<br>    2. 件数下限不能大于件数上限。<br>    3. 开单件数 ≥ 下限，且 ≤ 上限，才达标。重量、件数两个都要满足。<br>8. **剔除网点**（仅配置范围=分拨时显示）<br>    1. **控件：**分拨中心组件，多选；**可输入范围：**当前开单分拨下属网点；**默认值：**空；非必填。<br>    2. 填了的网点不按该分拨行，也不按全国行。<br>9. 取消：关闭弹框，不保存。<br>10. 确定：<br>    1. 校验是否符合**新增弹框**字段规则。<br>        1. 否：不保存。缺必填提示「请完善必填项」；件数下限大于上限提示「件数下限不能大于件数上限」；重量不大于 0 或超出三位整数、两位小数提示「重量阈值格式不正确：最多3位整数+2位小数」；件数不是正整数提示「件数须为正整数」。<br>        2. 是：进行**唯一性校验**。逻辑：<br>            1. **全国**<br>                1. 按每个已勾选的分拨类型，查已有全国行是否已包含该类型。<br>                    1. 都不包含：校验通过 → 关闭弹框，保存成功。<br>                    2. 任一类型已存在：校验不通过 → 提示「该分拨类型已有全国配置」，不保存。<br>            2. **分拨**<br>                1. 按开单网点/分拨查已有分拨行是否已有该分拨。<br>                    1. 没有：校验通过 → 关闭弹框，保存成功。<br>                    2. 已有：校验不通过 → 提示「该分拨已有配置」，不保存。<br>            3. **网点**<br>                1. 按开单网点/分拨查已有网点行是否已有该网点。<br>                    1. 没有：校验通过 → 关闭弹框，保存成功。<br>                    2. 已有：校验不通过 → 提示「该网点已有配置」，不保存。 |
| 编辑 | 1. 须勾选 1 条。未勾选或勾选多条，提示「请选择一条数据」。<br>2. 弹框字段与新增相同。配置范围、分拨类型、开单网点/分拨不可改；重量阈值、件数下限、件数上限、剔除网点可改。<br>3. 确定：按上述「新增」确定的字段规则校验。唯一性校验排除本条。通过则关闭弹框，保存成功；不通过提示与新增相同。 |
| 删除 | 1. 须至少勾选 1 条。未勾选提示「请选择要删除的数据」。<br>2. 确认提示：「删除后不可恢复，请确认是否删除！（共 X 条）」。<br>3. 确定后删除所选行，列表刷新。 |
| 导入 | 1. **上传触发**<br>    1. 点击导入后由用户选择本地文件上传。模版：`维护_导入模版.xlsx`。<br>2. **导入校验**<br>    1. 校验导入文件内容是否符合**新增弹框**字段规则（配置范围决定哪些列必填：全国必填分拨类型；分拨必填开单分拨；网点必填开单网点；剔除网点仅分拨行可填）。<br>        1. 否：**整份文件导入失败**，自动下载失败文件，问题行提示具体失败原因。<br>        2. 是：进行**唯一性校验**。逻辑：<br>            1. **全国**<br>                1. 按分拨类型校验文件内、以及已有全国行是否重复。<br>                    1. 不重复：校验通过。<br>                    2. 重复：校验不通过。<br>            2. **分拨**<br>                1. 按开单分拨校验文件内、以及已有分拨行是否重复。<br>                    1. 不重复：校验通过。<br>                    2. 重复：校验不通过。<br>            3. **网点**<br>                1. 按开单网点校验文件内、以及已有网点行是否重复。<br>                    1. 不重复：校验通过。<br>                    2. 重复：校验不通过。<br>            4. **整体导入成功/失败规则**<br>                1. 校验范围：文件全部数据行。<br>                2. 导入判定逻辑：<br>                    1. 全部数据校验无误 → 整份文件导入成功。<br>                    2. 任一数据校验不通过 → **整份文件导入失败**，自动下载失败文件，问题行提示具体失败原因。 |
| 导出 | 1. 按当前查询条件导出，不勾选也导出全部查询结果。<br>2. 列与列表一致。文件名：`操作大票维护.xlsx`。 |

##### 验收要点

| 序号 | 验收要点 |
| --- | --- |
| 1 | 配置范围可多选全国、分拨、网点；不选时该条件不过滤 |
| 2 | 剔除网点可多选；选中网点与列表「剔除网点」有交集才查出；不选时该条件不过滤 |
| 3 | 全国行必须勾分拨类型；只勾直营分拨时，仅该类型走这一行 |
| 4 | 同一分拨类型不能有两条全国配置；同一分拨、同一网点不能各有两条 |
| 5 | 开单结算重量 ≥ 重量阈值，且件数 ≥ 下限、≤ 上限，才算达标；重量、件数都要满足 |
| 6 | 有网点行按网点行；否则有分拨行按分拨行；否则有对应类型的全国行按全国行 |
| 7 | 分拨行剔除的网点，不按该分拨行，也不按全国行 |
| 8 | 导入任一行不通过则整份失败，并下载带失败原因的文件 |
| 9 | 全国配置只有总部能新增、编辑、删除、导入；其他人可以查看 |
| 10 | 重量阈值最多三位整数、两位小数；无对应按钮权限时按钮不展示 |

#### 运单列表

查操作大票运单。当前按维护门槛命中的进本页；开单时未命中、后来才命中的也进。开单时是、改单后不再是的（含改成提货方式=中心派车提货），仍留在本页。开单时提货方式就是中心派车提货的，不进。

##### 数据进表与刷新

说明：下列是业务要达到的效果。具体怎么执行（定时、实时、消息等）评审时跟开发一起定；能做实时的优先实时。

| 类型 | 业务效果 |
| --- | --- |
| 开单进表 | 按小时处理近一小时的开单。满足操作大票规则的写入本页。开单时提货方式=中心派车提货的不写。 |
| 改单-更新已有数据 | 按小时处理近一小时的改单。只处理目的分拨装车时间为空、且已在本页的运单：更新是否改单、改单时间、改单后是否为大票，以及改单带来的运单字段（如提货方式、送货方式、件数、结算重量等）。目的分拨装车时间已有值的，本次不更新。 |
| 改单-抓新进表 | 同上批改单里，还不在本页、但当前已满足操作大票规则的，抓进本页。 |
| 改单后不再是操作大票 | 已在本页的不删。是否改单=是，改单后是否为大票=否。改成提货方式=中心派车提货的，同样留着，按本行处理。 |
| 实时字段 | 目的分拨封签到车时间、目的分拨 GPS 到达时间、目的分拨卸出时间、目的分拨卸出扫描人、目的分拨扫描人岗位、目的分拨装车时间、签收状态、签收时间、是否已发短信，以及行标红所用到的到车/卸出：跟现网变化实时更新，不靠小时任务刷。电脑「卸出并通知」、发短信成功：当场改是否已发短信。 |

| 名称 | 说明 |
| --- | --- |
| 卸出并通知 | 1. 未勾选：按钮置灰，不可点。<br>2. 已勾选：每一条都须同时满足——当前登录分拨是该运单目的分拨，送货方式=中心自提，目的分拨封签到车时间或目的分拨 GPS 到达时间有值，目的分拨卸出时间为空，且本票还没有电脑「卸出并通知」写下的卸车轨迹。有一条不满足：不弹框，提示「请选择已到车且未卸出的中心自提运单」，本次不处理。<br>3. 都满足：确认提示「确认对所选运单电脑卸出并通知提货吗？本次只写轨迹、不计货量，系统自动发短信。」<br>    1. 取消：关闭，不写轨迹，不发短信。<br>    2. 确定：按下方「电脑与 PDA 卸出（扫两次）」处理电脑侧；是否已发短信=否时发提货短信并改为是；已经是是的不再发。 |

##### 电脑与 PDA 卸出（扫两次）

目的分拨、中心自提：允许电脑先点「卸出并通知」，操作工再用 PDA 卸出。两段数据拆开，避免整段扫描逻辑跑两遍重复。

| 谁 | 写什么 | 不写什么 |
| --- | --- | --- |
| 电脑「卸出并通知」 | 卸车轨迹（仓储费按轨迹算，所以这里要有轨迹）。发提货短信（规则见「提货短信」） | 库存、货量、目的分拨卸出时间、目的分拨卸出扫描人、目的分拨扫描人岗位；其他卸出业务数据也不写 |
| PDA 再卸（本票已有电脑卸车轨迹） | 库存等其余卸出数据；货量类型=【操作大票计入货量】；目的分拨卸出时间、卸出扫描人、扫描人岗位 | 卸车轨迹（电脑已写过，不再写一条） |
| 仅 PDA 卸、电脑没点过 | 按操作大票完整卸出：轨迹、库存、货量等都写（与现网整票卸出一致） | — |

说明：轨迹/库存具体落哪些现网对象，评审时跟开发对齐；上表是业务拆分口径。
| 导出 | 1. 按当前查询条件导出，不勾选也导出全部查询结果。<br>2. 列与列表一致。文件名：`操作大票运单列表.xlsx`。 |

##### 提货短信

发给该票客户，通知来提货。没有单独的发短信按钮。运单列表「卸出并通知」和 PDA 目的分拨卸车点「继续卸车」共用该规则。是否已发短信=是的，不再发。

已到车：目的分拨封签到车时间、目的分拨 GPS 到达时间，有一个有值即可。

| 场景 | 是否发短信 |
| --- | --- |
| 目的分拨，送货方式=中心自提，已到车，还没 PDA 卸出，是否已发短信=否。运单列表「卸出并通知」点确定 | 发一条，是否已发短信改为是。只写电脑侧卸车轨迹，不写库存和货量 |
| 目的分拨，送货方式=中心自提，是否已发短信=否。PDA 卸车弹框点「继续卸车」 | 发一条，和上面同一条，是否已发短信改为是 |
| 上面两种，是否已发短信已经是是 | 不再发。PDA 点「继续卸车」仍完成本次卸车（有电脑轨迹则不再写轨迹，写库存和货量） |
| 上面两种点取消 | 不发，是否已发短信不改 |
| 送货方式=网点派送、网点自提、中心直送 | 不发 |
| 首分拨、中转分拨卸车 | 不发 |
| 未到车 | 不发 |

发给该运单的收件客户手机号。手机号为空时不发，是否已发短信仍为否。

短信正文：您的货物已到达{目的分拨中心}，运单号{运单号}，请前来提货。

##### 验收要点

| 序号 | 验收要点 |
| --- | --- |
| 1 | 当前命中操作大票的可查到；开单时未命中、后来才命中的也能查到。开单时提货方式就是中心派车提货的不进本页 |
| 2 | 开单时是、改单后不再是的（含改成中心派车提货），仍在本页：是否改单=是，改单后是否为大票=否。开单时不是、后来变成的：是否改单=是，改单后是否为大票=是。没改过单：是否改单=否，改单后是否为大票为「-」 |
