# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|因在自动补打前，该分拨手动补打后，界面就一直展示未打印，容易误导用户。|
|V1\.1\.1|因退单没有任何扫描记录，导致双库分拨不知道由哪个分拨来自动补打。|
|V1\.1\.2|银川、兰州分拨中心转为了直营分拨中心，但是网点类型还是二级财务中心，现在打印分拨查询条件限制了不能查询二级财务中心的数据。|
|V1\.2\.0|网点改单分拨环节自动审核通过，并且改单内容包含改目的网点或件数的需要中心补打贴单。|
|V2\.0\.0|当前的拦截改单换单流程为：货物入库后，由自动补打系统打印出新的子单。操作人员将这些需要改单的货物放置在专门的“拦截改单货区”，再由异常处理人员统一重新贴单。然而，这种流程导致了换单过程滞后，影响了货物的处理时效，并且异常处理岗位的工作压力过大。|
