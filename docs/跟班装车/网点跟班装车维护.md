# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|1. **未进装车货区的货也会进交接单，被判未按时发走并罚款。** 现按清仓时间准时发车，子单移动自动出库后归属交接单。例如清仓 10:00，9:55 移动扫描的货会进 10:00 交接单，但货未到装车货区、实际未装上车，服务质量按未按时发走考核，分拨被罚款。<br>2. **取消跟班后查不到取消时间，核查难。** 服务质量后期核对时，网点已取消跟班却难以直接查清取消时间。<br>3. **OA 走完仍靠人工新增名单，费时费力。** 「网点跟班操作报备申请」审批通过后还要人工录入，希望系统自动新增。|

# 三、产品分析

## 3\.2  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|1. **时效 / 罚款：** 希望按全国、分拨、网点配置提前发车时长，让发车与交接单切换相对清仓提前，减少「已进交接单、货未装上车」被考核的情况。<br>2. **核查：** 取消跟班后要能查到取消时间，增删改进变更记录。<br>3. **OA：** 审批通过后系统自动新增网点跟班名单，不再每次人工录入；不读扫描模式，移动自动出库逻辑固定自动出库、二次移动自动出库固定否、提前发车时长（分钟）空着不填。|

## 3\.2  产品方案

|**版本**|**产品方案**|
|---|---|
|V1\.0\.0|建设【网点跟班装车维护】三 Tab：网点跟班名单、提前发车时长、变更记录。支持全国 / 分拨 / 网点配置提前发车时长；网点跟班名单列表展示最终提前发车时长（本行填写 \> 分拨 \> 全国，都无则 0）。删除后名单不展示，取消时间在变更记录可查。OA 审批通过后自动增删网点跟班名单并推企业微信。使用侧怎么扣时间见【跟班装车网点移动自动出库】。|
