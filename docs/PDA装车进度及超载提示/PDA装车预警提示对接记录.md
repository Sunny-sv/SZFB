# PDA装车预警提示对接记录

> 整理日期：2026-09-12  
> 需求负责人：胡绵飞  
> 对接方：时效组-杨勇  
> 对应 PRD：[PDA装车进度及超载提示.md](./PDA装车进度及超载提示.md) V1.1.0  

## 对接诉求

1. 装载率展示改成向下取：实重装载率取整到整数%；体积装载率保留一位小数且末位向下取，避免一线误以为已到 75% 而不再装。
2. 剩余可装吨提示仍走配置档位，文案用整数吨；算法为真实剩余吨向上取整，鼓励往多装。
3. 只要超过额定重量就弹超重提示，展示具体超重公斤，允许继续装；强制拦截配置保留作锁扫兜底。
4. 超重统一走超重弹窗，不另读配置开关；强制拦截字段保留。

## 已确认结论

| 项 | 结论 |
| --- | --- |
| 版本 | 新开 **V1.1.0** 增量；不回改 V1.0.0 正文 |
| 实重装载率展示 | 向下取整到整数%（仅展示） |
| 体积装载率展示 | 保留 1 位小数并向下取；如 `额定体积：130 (74.9%)` |
| 展示与判断 | 百分比只改展示；剩余吨按 n 比档（已超额定不弹剩余吨）；超重/强制拦截用真实已装公斤 |
| 剩余可装 n | n = 向上取整((额定−已装)÷1000)；例：还剩 1.5 → n=2；还剩 17.5 → n=18 |
| 档位来源 | 仍读【装车预警配置维护】提示次数与各档上限 |
| 跨档一票跳过 | 只补弹扫入后所在档 |
| 剩余吨弹窗 | 各档首次进入弹 1 次；不锁扫；文案整数吨 |
| 超重触发 | 试算后已装 ＞ 额定重量即弹；不另加 PC 开关 |
| 超重文案 | 展示具体超重公斤数（**固定两位小数**）；每件都提示；语音播报「已超重，请核实」 |
| 强行装入 / 取消装入 | 仅强行装入按钮停顿 T 秒（系统参数，全国一个值，默认 5，配 0=不停顿；参数编码名待研发落名）：取消装入可立即点；强行装入须满 T 秒后可点（T=0 可立刻点）；取消=本票未装；强行装入=本件扫描成功；关窗后仍可扫描 |
| 强制拦截取整 | 强制%：向下取整(已装÷额定×100)≥配置%；强制吨：向下取整((已装−额定)÷1000)≥配置吨（偏晚拦，利于多装） |
| 强制 vs 超重优先级 | 同一票两种都满足时：强制拦截优先，只走强制、不弹超重提醒 |
| 与强制拦截 | 开启且命中 → 锁扫、不可强装；未开或未命中 → 走超重可强装 |
| n≤0 / 已超额定 | n≤0 不弹剩余吨；已装＞额定只走超重弹窗 |
| 流水装车 | 维持只展双%、不提示不拦截不走超重强装 |
| 覆盖菜单 | 与 V1.0.0 相同：网点装车、实时装车、特殊装车、项目客户装车 |

## 备注

1. 业务背景：一线倾向多装拿奖励；超重后有人发车前问文员是否超重；外租车能上高速、自有车司机不愿超等原因，故超重允许强装、强制拦截作可选兜底。
2. 超重弹窗：语音「已超重，请核实」；仅强行装入按钮停顿 T 秒（系统参数默认 5，配 0 可立刻点；参数编码名待研发落名）；取消装入可立即点；强行装入=本件扫描成功（2026-09-14 补充确认）。
3. 超重提醒不另读配置开关；强制拦截字段保留，命中后仍锁扫。
4. 详细规则与验收见 PRD V1.1.0；业务核对举例已按本版整表重写。
