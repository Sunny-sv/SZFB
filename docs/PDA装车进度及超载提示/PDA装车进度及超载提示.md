|**版本**|**要解决的问题**|
|---|---|
|V1\.0\.0|PDA装车不向一线展示已装实际重量后，员工无法判断装车完成程度，也难以预判超载，存在作业节奏难把控与合规/运输安全风险。|

## 5\.2 需求描述

### V1\.0\.0

适用范围：

- 适用：直营分拨中心、非直营分拨中心、服务站、直营集配站、非直营集配站

- 不适用/限制：不限制（是否弹提示/拦截由PC端配置决定）

配置取值见 [装车预警配置维护](https://my.feishu.cn/docx/M3h1dVqp4oyHQXxqLvCc9u6enNb?from=from_copylink)。本需求只写PDA侧展示与作业表现。

#### 展示边界

1. PDA **不展示**已装货物实际重量数值。

2. **保留**「额定重量」「额定体积」；数值只展示整数（去掉小数）。

3. 同行追加整数百分比，**不写**「重量百分比」「体积百分比」等字段名：    

    ```
    额定重量：27000 (72%)
    额定体积：130 (45%)
    ```

4. 一线可见额定\+百分比时可估算已装量；业务确认仍同时展示。

5. 覆盖菜单：凡展示额定重量/额定体积的装车页，含**网点装车**、**实时装车**、**特殊装车**、**项目客户装车**、**流水装车**。其余能力（列表、发车、破损、切换交接单等）沿用现网。

#### 进度计算

|**指标**|**公式**|
|---|---|
|重量进度%|车内已装实际重量 ÷ 车辆额定重量 × 100%，向上取整。|
|体积进度%|车内已装实际体积 ÷ 车辆额定体积 × 100%，向上取整。|

**车内已装重量/体积（有无汽运任务）：**

|**场景**|**取数**|
|---|---|
|**有汽运任务**|本任务号下交接单，按主任务车线过滤后汇总：上一站不晚于当前装车分拨，且下一站晚于当前装车分拨；再分别汇总已装子单实际重量/已装子单体积|
|**无汽运任务**|只取**当前交接单**已装子单实际重量/已装子单体积|

有汽运过滤含义：本站已卸段不计入；下游站才建的交接单（如当前在B时装，C→D）不计入。

**举例（有汽运，车线A→B→C→D，当前在B）：**

|**本任务下交接单**|**是否计入**|
|---|---|
|A→B|否|
|A→C / A→D|是|
|B→C / B→D|是|
|C→D|否|

##### 额定缺失

|**缺失项**|**展示**|
|---|---|
|未取到额定重量|该行不展示重量%；展示「未获取到额定重量」|
|未取到额定体积|该行不展示体积%；展示「未获取到额定体积」|

缺额定不算对应进度，**不因此锁扫**；与另一额定是否有值无关。

##### 展示与刷新

1. 额定数值**直接截断小数**、百分比**向上取整**（展示用）。剩余吨提示、强制超载吨的取整见下文，不与本条混用。

2. 装车扫描成功、**单号撤销成功**。

3. 切换交接单：按当前交接单重算（有汽运仍按任务过滤）。

4. 多人同装：以服务端汇总为准，各PDA展示同一进度。

|**操作类型**|**菜单**|
|---|---|
|网点|网点装车|
|干线|实时装车、特殊装车、项目客户装车|
|—（特例）|**流水装车**：按干线口径只算只展双百分比；**不读**提示档、**不**强制拦截|

#### 配置命中与策略开关

**命中顺序：**

1. 当前装车分拨\+当前操作类型有分拨配置 → 用分拨配置（不受全国「适用分拨类型」约束）

2. 否则取该操作类型的全国配置，且当前分拨类型属于「适用分拨类型」→ 用全国

3. 否则：只展示双百分比，不提示、不拦截

**两项开关组合：**

|**开启剩余吨位提示**|**开启强制拦截**|**PDA表现**|
|---|---|---|
|是|是|达档弹剩余吨提示（不锁扫）；达强制条件弹窗并锁扫|
|是|否|只弹剩余吨提示，不锁扫|
|否|是|不弹剩余吨提示；达强制条件仍弹窗并锁扫|
|否|否|只展示双百分比|

#### 剩余吨位提示（不锁扫）

仅当命中配置且「开启剩余吨位提示 = 是」时生效。

1. 剩余可装（吨）=（额定重量 − 车内已装实际重量）÷ 1000，再**向下取整**；比档与文案都用该整数吨（例：4\.7→4，5\.9→5）。

2. 档位数 = 配置「提示次数」；各档「剩余可装上限吨」严格递减。

3. **落档：**第k档首次进入「下一档上限 ＜ 剩余 ≤ 本档上限」时弹1次；**末档**为「剩余 ≤ 末档上限」。只维护一档时该档即末档，条件为「剩余 ≤ 本档上限」，进入后直至会话结束同档不重复弹。

4. 同一装车会话内各档首次进入各弹1次；关后仍处该档不反复弹；撤货/撤销降档后再升回可再弹。

5. **不禁止**装车扫描。

**弹窗：**

|**项**|**内容**|
|---|---|
|正文|剩余可装 \{n\} 吨，请注意超载！|
|数字样式|\{n\} **放大、加粗、红色**|
|按钮|知道了|

体积不参与吨提示与强制判断。

#### 强制拦截

仅当命中配置且「开启强制拦截 = 是」时生效。配置侧强制%与强制吨至少维护一项；PDA **只判断已维护的项**。

先算：

- **重量进度相关：**车内已装实际重量、额定重量（缺额定重量时不做强制判断、不锁扫）

- **超载吨** =（车内已装实际重量 − 额定重量）÷ 1000，再**向上取整**（有小数就进1；可为负：未满载；为0：满载附近；为正：已超载。例：1\.1→2，−0\.0001→0）

|**已维护项**|**命中条件**|**弹窗正文**|
|---|---|---|
|仅强制拦截%|在车已装实际重量 ≥ 额定重量 × 强制拦截%|车辆已超额定载重 \{配置%\}%，禁止继续装车|
|仅强制拦截吨|超载吨 ≥ 强制拦截吨|车辆已超载至限制吨位，系统已禁止继续扫描装车|
|两项都维护|满足上述**任一**即命中|同时命中时优先展示百分比文案|

强制拦截吨业务含义：限制「超载到多少吨后禁止再装」。例：配2 → 超载吨不低于2即拦（真实超1\.1吨即拦）；配0 → 超载吨不低于0即拦（含差一丁点未满额定、向上取整为0的情况）；配\-1 → 超载吨不低于\-1即拦。

规则：

1. **试算拦截：**本票扫入后将命中已维护条件中的任一项 → 本票不能扫描、不入账，并弹对应文案。

2. 关闭弹窗不等于解除拦截；条件未解除前仍禁止装车扫描。

3. **仅拦截装车扫描**；发车、切换交接单、无头件、破损等沿用现网。

4. 撤销等使条件不再满足后自动解锁。

#### 验收要点

|**序号**|**验收要点**|
|---|---|
|1|不展示已装实际重量；额定重量/体积为整数；同行分别展示重量%、体积%，无百分比字段名|

### V1\.1\.0

配置命中顺序、操作类型菜单映射、有无汽运取在车货量、缺额定展示、流水装车只展双%、强制拦截的锁扫范围与试算拒扫（仅拦装车扫描、命中文案优先级等）沿用现网，本版不改。本版只写下列改动（含强制拦截**取整方向**相对现网的调整）。

#### 双百分比展示（改取整）

|**指标**|**展示规则**|
|---|---|
|重量进度%|车内已装实际重量 ÷ 额定重量 × 100%，**向下取整到整数**（例：98\.1%、98\.9% 均展示 98%）|
|体积进度%|车内已装实际体积 ÷ 额定体积 × 100%，**保留 1 位小数且末位向下取**（例：74\.99% → 74\.9%）|

展示样式示例：

```
额定重量：27000 (98%)
额定体积：130 (74.9%)
```

**展示与判断分离：** 上述百分比取整**只用于页面展示**，不做提示/拦截判断。各判断口径：

|**用途**|**用什么数**|
|---|---|
|剩余吨提示|真实剩余吨**向上取整**得整数 n 再比档；已装＞额定或 n≤0 不弹剩余吨（不用展示用的重量%）|
|超重提醒|试算后**真实已装公斤**与额定重量比；超重公斤固定展示**两位小数**|
|强制拦截|按下方「强制拦截取整」：% 与吨判断都**向下取整**后再比（偏晚拦，利于多装）|

#### 剩余吨位提示（改 n 算法与跨档）

仅当命中配置且「开启剩余吨位提示 = 是」时生效。档位数、各档上限仍读【装车预警配置维护】。

1. **剩余可装 n（吨）** = 向上取整((额定重量 − 车内已装实际重量) ÷ 1000)。即：先算真实还能装几吨，再向上取整。例：额定 27000 kg、已装 25500 kg → 真实还剩 1\.5 吨 → n = **2**（提示偏大，鼓励多装）。再例：额定 27500 kg、已装 10000 kg → 真实还剩 17\.5 吨 → n = **18**。
2. 落档仍用相邻上限夹区间；末档为 n ≤ 末档上限；只维护一档时该档即末档。比档与弹窗文案都用该整数 n。

    **多档示例（配置提示吨位 5 / 3 / 1）：**

    |**档**|**落档条件**|**例：n 取值**|**首次进入时弹窗**|
    |---|---|---|---|
    |第 1 档（上限 5）|下一档上限 ＜ n ≤ 本档上限，即 **3 ＜ n ≤ 5**|n=5、4|剩余可装 **5** / **4** 吨…（文案用当前 n，不是固定写 5）|
    |第 2 档（上限 3）|**1 ＜ n ≤ 3**|n=3、2|剩余可装 **3** / **2** 吨…|
    |第 3 档（末档上限 1）|**n ≤ 1**（且 n ＞ 0，见下条）|n=1|剩余可装 **1** 吨…|

    **只维护一档示例（只配上限 5）：** 该档即末档，条件为 **n ≤ 5**（且 n ＞ 0）。n=5 首次弹「剩余可装 5 吨…」；之后 n=4、3、2、1 仍属同一档，不重复弹。n=6 不弹。
3. **跨档一票跳过：** 只补弹**扫入后所在档**；中间漏掉的档不补弹。同档内首次进入弹 1 次，不重复弹。
4. **n ≤ 0：** 不弹剩余吨提示。**已装 ＞ 额定重量：** 只走超重提醒，不弹剩余吨提示。
5. 弹窗正文仍为：剩余可装 \{n\} 吨，请注意超载！（\{n\} 放大、加粗、红色；按钮「知道了」）。

#### 超重提醒（可强装）与强制拦截并存

**优先级（同一票试算可能两种都满足时）：强制拦截 ＞ 超重提醒。** 先判强制拦截；命中则只走强制（锁扫、本件不成功），**不再弹**超重提醒。未命中强制时，再判是否已装＞额定走超重提醒。

|**条件（按优先级从上到下）**|**表现**|
|---|---|
|1. 开启强制拦截 = 是，且试算命中已维护的强制%/强制吨（取整见下）|只弹强制文案、**锁扫**、本票不入账；**不可**强行装入；不弹超重窗|
|2. 未走强制（未开或未命中），且试算后已装 **＞** 额定重量|弹超重提醒（见下）；**不锁扫**|
|3. 已装 ≤ 额定重量|不弹超重窗、不强制|

**强制拦截取整（本版相对现网调整，利于多装）：** 缺额定重量时仍不做强制判断、不锁扫。只判断已维护的强制%/强制吨；两项都维护时任一命中即拦，同时命中优先百分比文案（沿用现网）。**按试算判断：** 本票扫入后的在车已装做试算，试算结果命中强制条件 → **本票扫描不成功、不上传**，并弹强制拦截弹框（最后这一件装不进去）。

|**已维护项**|**怎么算、怎么比**|**举例（额定 27000 kg）**|
|---|---|---|
|强制拦截%|装载率 = 向下取整(已装 ÷ 额定 × 100)；**装载率 ≥ 强制拦截%** 即命中|配 120：已装 32399 → 装载率 119 → 不拦；已装 32400 → 120 → 拦|
|强制拦截吨|超载吨 = 向下取整((已装 − 额定) ÷ 1000)；**超载吨 ≥ 强制拦截吨** 即命中|配 2：已装 28100（真实超 1\.1 吨）→ 超载吨 1 → 不拦；已装 29000（真实超 2 吨）→ 2 → 拦|

说明：强制吨由现网「超载吨向上取整」改为**向下取整**，同一配置下会更晚触发锁扫。强制%用向下取整后的装载率与配置比，未进到配置整数%前不拦。

超重提醒（仅上表第二行）：

|**项**|**规则**|
