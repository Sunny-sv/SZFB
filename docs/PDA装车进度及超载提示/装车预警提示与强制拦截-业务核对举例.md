# 装车预警提示怎么弹 — 业务核对举例（V1.1.0）

> **状态：按 V1.1.0 落地；V1.0.0「剩余向下取整 / 仅强制拦截」旧举例作废。**  
> 正式规则见 `PDA装车进度及超载提示.md` V1.1.0。  
> 共用前提：额定重量 **27000 kg**（27 吨）；流水装车不弹、不拦、不走超重强装。

**取整对照：**

| 用在哪 | 怎么取整 / 怎么算 | 例子 |
| --- | --- | --- |
| 重量%（仅展示） | 向下取整到整数 | 98.1%→**98%**；98.9%→**98%** |
| 体积%（仅展示） | 一位小数，末位向下取 | 74.99%→**74.9%** |
| 剩余可装 n（提示） | **向上取整**((额定−已装)÷1000) | 已装 25500 → 还剩 1.5 → n=**2**；额定 27500、已装 10000 → 还剩 17.5 → n=**18** |
| 强制超载吨（锁扫） | （已装−额定）÷1000 **向下取整**（本版；利于多装） | 1.1→**1**（配拦 2 时不拦）；2.0→**2** |
| 强制装载率%（锁扫） | 向下取整(已装÷额定×100) 再与配置%比 | 32399→**119**（配 120 不拦）；32400→**120** |

判断口径（都不用展示用的百分比做剩余/超重文案；强制%判断用向下取整后的装载率）：

| 用途 | 用什么数 |
| --- | --- |
| 剩余吨提示 | 真实剩余吨向上取整得 n 再比档；已装＞额定或 n≤0 不弹剩余吨 |
| 超重 | 真实已装 − 额定（公斤，**固定两位小数**） |
| 强制拦截 | %：向下取整装载率；吨：向下取整超载吨 |

## 一、剩余吨位提示（不锁扫）

**算什么：** n = 向上取整((额定 − 已装) ÷ 1000)。  
**已超额定或 n≤0：** 不弹剩余吨；已装＞额定只走超重窗。  
**弹什么：** `剩余可装 {n} 吨，请注意超载！`（n 放大加粗红色）  
**拦不拦：** 不拦。  
**跨档：** 一票跳过多档时，**只弹扫入后所在档**。

多档例：配 5 → 3 → 1（用 n 落档）

| 档 | 落档条件 |
| --- | --- |
| 第 1 档（上限 5） | **3 ＜ n ≤ 5** |
| 第 2 档（上限 3） | **1 ＜ n ≤ 3** |
| 第 3 档（末档上限 1） | **n ≤ 1**（n≤0 时按上条不弹） |

扫货举例：

| 已装（kg） | 真实还剩（吨） | n（B） | 会不会弹 |
| --- | --- | --- | --- |
| 21000 | 6.0 | 6 | 不弹 |
| 22000 | 5.0 | **5** | 首次弹「剩余可装 **5** 吨…」 |
| 23000 | 4.0 | **4** | 同档（3＜4≤5）不重复弹 |
| 23999.9 | 约 3.0001 | **4**（向上取整 3.0001） | n=4 属第 1 档（3＜n≤5），同档不重复 |
| 24000 | 3.0 | **3** | 首次弹「剩余可装 **3** 吨…」 |
| 24666 | 约 2.334 | **3**（27−24） | 同档不重复；若一票从 n=6 直接到 n=3，**只弹 3**，不补弹 5 |
| 25500 | 1.5 | **2** | 属 1＜n≤3；若 3 吨档已弹过则不重复；文案为「剩余可装 **2** 吨」 |
| 26000 | 1.0 | **1** | 属末档 n≤1；首次弹「剩余可装 **1** 吨…」 |
| 26500 | 0.5 | **1** | 同档（n=1）不重复弹 |

## 二、超重提醒（强制拦截关或未命中时）

**触发：** 试算后已装 **＞** 27000。  
**弹什么：** 超重具体公斤 + **强行装入 / 取消装入**；**每件都提示**。  
**语音：** 弹窗出现时播报「已超重，请核实」。  
**停顿：** 仅**强行装入**按钮停顿 **T** 秒（系统参数，全国一个值，默认 5；配 0=不停顿；参数编码名待研发落名）——**取消装入**可立即点；**强行装入**须满 T 秒后才可点（T=0 可立刻点）。  
**取消装入：** 本票未装。  
**强行装入：** 本件扫描成功。  
**关窗：** 不锁扫，还可继续扫。

| 试算后已装 | 期望 |
| --- | --- |
| 26999 / 27000 | 不弹超重 |
| 27100.01 | 弹超重 **100.01** 公斤（两位小数）；语音「已超重，请核实」；取消立即可点；强装须满 T 秒（默认 5） |
| 27001.01 | 弹超重 **1.01** 公斤（两位小数）；同上 |
| 28000 | 弹超重 **1000.00** 公斤（整数也补两位小数）；同上 |
| 系统参数 T=0 | 强行装入可立刻点 |
| 已超重后再扫下一件 | **再弹**（每件） |

## 三、强制拦截（开且命中）

命中强制%/强制吨 → **锁扫、不可强装**；与超重同时满足时**只走强制，不弹超重**。判断取整按本版**向下取整**（利于多装）。  
未到强制线但已装＞额定 → 才走第二节超重可强装。

**仅强制% =120**

| 已装 | 装载率（向下取整） | 期望 |
| --- | --- | --- |
| 32399 | 119 | 不拦；已超额定则超重可强装 |
| 32400 | 120 | 强制锁扫，不可强装 |

**仅强制吨 =2**

| 已装 | 真实超了（吨） | 超载吨（向下） | 期望 |
| --- | --- | --- | --- |
| 28100 | 1.1 | **1** | 不拦；超重可强装 |
| 29000 | 2.0 | **2** | 强制锁扫，不可强装 |
