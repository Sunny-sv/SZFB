## 5.3 需求描述

### V1.0.0

下游 PDA 命中与表现见 [PDA装车进度及超载提示.md](./PDA装车进度及超载提示.md)，本页只写配置维护。

适用范围：

- 适用：直营分拨中心、非直营分拨中心、服务站、直营集配站、非直营集配站
- 不适用/限制：不限制

**命中口径（供研发对齐，页面本身不展示）：** 同分拨+同操作类型的分拨配置优先；无分拨配置时用同操作类型全国配置，且当前分拨类型须在「适用分拨类型」内；否则 PDA 不提示不拦截（百分比仍展示）。

**两项开关：** 可同为是、同为否，或一开一关；互不强制联动。

#### 查询条件


| 名称 | 控件 | 说明 |
| --- | --- | --- |
| 配置范围 | 单选下拉框 | 1. 枚举：全部、全国、分拨。<br>2. 默认：**全部**。<br>3. 空/全部：不按配置范围过滤。<br>4. 查询逻辑：等于选中项。 |
| 分拨中心 | 分拨中心组件（多选） | 1. 默认空，空则不按分拨过滤。<br>2. 查询逻辑：列表分拨中心命中所选分拨之一即命中。<br>3. 全国配置行的分拨中心展示为「-」，查询分拨时不命中全国行。 |
| 操作类型 | 单选下拉框 | 1. 枚举：全部、干线、网点。<br>2. 默认：**全部**。<br>3. 空/全部不生效。<br>4. 查询逻辑：等于选中项。 |
| 开启剩余吨位提示 | 单选下拉框 | 1. 枚举：全部、是、否。<br>2. 默认：**全部**。<br>3. 空/全部不生效。 |
| 开启强制拦截 | 单选下拉框 | 1. 枚举：全部、是、否。<br>2. 默认：**全部**。<br>3. 空/全部不生效。 |


#### 按钮操作


| 名称 | 说明 |
| --- | --- |
| 新增 | 1. 打开新增弹框。<br>2. **弹框字段**<br>    1. **配置范围**：单选下拉框；全国、分拨；必填；分拨、省区登录默认分拨，总部登录默认空。<br>    2. **分拨中心**：分拨中心组件；配置范围=分拨时必填、展示；=全国时不展示。<br>    3. **操作类型**：单选下拉框；干线、网点；必填；默认空。<br>    4. **适用分拨类型**：多选；枚举为直营分拨中心、非直营分拨中心、服务站、直营集配站、非直营集配站；配置范围=全国时必填至少一项；=分拨时不展示。<br>    5. **开启剩余吨位提示**：单选下拉框；是、否；必填；默认是。<br>    6. **提示次数**：数字输入框；开启剩余吨位提示=是时必填、展示；可填 1～5 的整数；决定下方档位行数；操作类型=干线时默认 3；=网点时默认 2。<br>    7. **提示吨位**：开启=是时展示且必填；按提示次数动态生成第 1～N 档「剩余可装上限（吨）」；各档默认空，由维护人填写；正整数；须严格递减（第 1 档最大）。<br>    8. **开启强制拦截**：单选下拉框；是、否；必填；操作类型=干线默认是；=网点默认否；与提示开关相互独立。<br>    9. **强制拦截%**：数字输入框；开启强制拦截=是时展示；与强制拦截吨**必填一项**；正整数；含义见 PDA：已装重量不低于额定×该%。<br>    10. **强制拦截吨**：数字输入框；开启强制拦截=是时展示；与强制拦截%**必填一项**；整数（可正可负）；含义：限制「超载到多少吨后禁止再装」。PDA 用（已装 − 额定）÷1000 **向上取整**后的超载吨，与配置值比较，超载吨不低于配置吨即锁扫。例：配 2=真实超 1.1 吨即按 2 拦；配 0=超载吨不低于 0 即拦；配 -1=超载吨不低于 -1 即拦。细则与举例见 PDA《装车进度及超载提示》。<br>3. **确定校验**<br>    1. 全国 + 同操作类型已存在：提示「该操作类型的全国配置已维护，无法重复维护」。<br>    2. 分拨 + 同分拨 + 同操作类型已存在：提示「该分拨该操作类型配置已维护，无法重复维护」。<br>    3. 开启提示时：提示次数与档位行数一致；各档须已填且严格递减，否则提示「提示吨位须严格递减」。<br>    4. 开启拦截时：强制拦截%与强制拦截吨至少填一项。<br>4. 取消：关闭不保存。<br>5. 保存成功：写入创建人、创建时间；修改人、修改时间与创建相同。 |
| 编辑 | 1. 须勾选且仅一条。<br>2. 弹框字段同新增；配置范围、分拨中心、操作类型置灰不可改。<br>3. 适用分拨类型、两项开关及关联字段可改。<br>4. 校验按上述；保存后更新修改人、修改时间。 |
| 删除 | 1. 至少勾选一条。<br>2. 弹框确认：「确认删除选中的配置吗？（共X条）」<br>3. 确定后删除并刷新；取消关闭。 |


本期不做导入、导出、变更记录。

#### 验收要点


| 序号 | 验收要点 |
| --- | --- |
| 1 | 可按配置范围、分拨、操作类型、两项开关查询；空条件不生效 |
| 2 | 全国可维护适用分拨类型；分拨配置不展示适用分拨类型、须选分拨中心 |
| 3 | 干线/网点可分别维护；全国同操作类型、同分拨同操作类型不可重复 |
| 4 | 开启剩余吨位提示=否时不展示/不校验提示次数与吨位；=是时次数 1～5，各档吨位默认空须手填，且严格递减 |
| 5 | 开启强制拦截=否时不展示强制字段；=是时强制%与强制吨至少填一项 |
| 6 | 两项开关可任意组合保存（含都关）；干线/网点表单默认开关与提示次数按上述，无灌库默认业务数据 |
| 7 | 列表展示创建人/时间、修改人/时间；编辑不改创建信息；删除需确认 |
| 8 | 无全国/分拨初始化灌库数据；未命中配置时 PDA 不提示、不拦截 |
| 9 | 全国仅总部可维；分拨配置数据权限沿用现网 |
| 10 | 分拨中心查询多选时，命中所选之一即可 |
| 11 | 强制拦截吨含义与 PDA 一致：超载吨=（已装−额定）÷1000 **向上取整**后再与配置比较 |
