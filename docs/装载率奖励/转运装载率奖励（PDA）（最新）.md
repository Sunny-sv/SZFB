# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|现装载率奖励都由总部转运专门安排一个人计算，耗费人力资源。|
|V2\.0\.0|1. 汽运新增串线线路，导致现在车线如果为串线线路装载率奖励计算会存在问题。<br>2. 体积装载率计算还在由总部人工计算。|
|V2\.1\.0|1. 网点性质为“集散点”的网点实际相当于个虚拟集配站，但是现在会计算装载率奖励，每次都要由人工将奖励金额修改为0\.<br>2. 上一站放空，B分拨发车时取不对流满仓长线还是按照A分拨的方案获取。|
|V5\.0\.0|1. 部分地区高速不限重，封签发车仍按额定重量判超重并取消装载率奖励，与当地业务实际不符。<br>2. 系统尚无按「取消超载考核配置」在算奖时跳过超载考核的能力，只能线下例外或误扣奖。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|人工计算太耗时耗力，希望能系统自动计算。|
|V2\.0\.0|1. 针对汽运串线线路，希望把串线线路拆分开按照单条线路计算。<br>2. 体积装载率希望系统能自动计算。|
|V2\.1\.0|1. 希望系统自动剔除集散点的数据。<br>2. 取不对流满仓长线时按照计算分拨跟目的分拨取方案。|
|V5\.0\.0|1. 命中【转运装载率方案维护】「取消超载考核配置」后，不因超载取消装载率奖励；装载率限制、晚发、不奖不罚仍按现网。<br>2. 「是否超载」仍按实重 vs 额定写事实值；另写「是否取消超载考核」供报表区分「真没超」与「超载但不考核」。<br>3. 上线后新封签发车按新规则；已出数明细不回刷。|

|**版本**|**产品方案**|
|---|---|
