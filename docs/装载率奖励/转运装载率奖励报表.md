# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|现装载率奖励都由总部转运专门安排一个人计算，耗费人力资源。|
|V2\.0\.0|1. 汽运新增串线线路，导致现在车线如果为串线线路装载率奖励计算会存在问题。<br>2. 体积装载率计算还在由总部人工计算。|
|V4\.0\.0|1. 现网「最终奖励金额」要求「是否超载=否」，命中取消超载考核后若仍记超载事实，最终奖会被算成 0，与「不考核超载仍可发奖」不符。<br>2. 明细无法区分「真没超载」与「超载但不考核」。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|人工计算太耗时耗力，希望能系统自动计算。|
|V2\.0\.0|1. 针对汽运串线线路，希望把串线线路拆分开按照单条线路计算。<br>2. 体积装载率希望系统能自动计算。|
|V4\.0\.0|1. 明细增加「是否取消超载考核」（是/否），与 PDA 出数一致；查询条件同步可筛。<br>2. 「是否超载」仍展示事实值；最终奖励在取消超载考核=是时不因超载清零。<br>3. 已出数不回刷。|

## 3\.2 产品方案

|**版本**|**产品方案**|
|---|---|
|V4\.0\.0|1. 明细信息（任务号维度）新增「是否取消超载考核」；查询条件新增同名字段。<br>2. 调整「最终奖励金额」：装载率限制通过、未晚发、非不奖不罚，且（未超载或取消超载考核=是）→ 展示奖励金额，否则 0。<br>3. 车线装载率情况 / 汇总信息继续汇总最终奖励金额，随公式自动带出。|
