# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|现装载率奖励都由总部转运专门安排一个人计算，耗费人力资源。|
|V4\.0\.0|1. 部分地区高速不限重，封签发车仍按额定重量做超载考核，命中后取消装载率奖励，与当地业务实际不符。<br>2. 系统尚无按「分拨中心 + 适用任务 + 可选车线下一站」维护「不考核超载」的能力，只能线下例外或误扣奖，对账难追溯。<br>3. 分拨装车（含发网点、无汽运任务车）装车超载提示/拦截与算奖考核同源白名单诉求，适用任务仅自有/外请无法单独覆盖无任务车。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|人工计算太耗时耗力，希望能系统自动计算。|
|V4\.0\.0|1. 业务希望对指定分拨、任务类型、可选车线下一站配置白名单：命中后不考核超载，装载率奖励仍按其余规则正常计发；装车侧命中后不再弹剩余吨/超重提醒、不强制拦截（见【PDA装车进度及超载提示】）。<br>2. 配置挂在【转运装载率方案维护】新 Tab「取消超载考核配置」；增删改走权限分配，不写死仅总部；分拨中心仍配分拨（不配网点），发网点方向用「车线下一站」表达。<br>3. 适用任务增加「无汽运任务」，便于分拨发网点无任务车单独开白名单；新增/编辑适用任务为多选（可勾多个类型；「全部」与分项互斥，「全部」含自有、外请、无汽运任务）。<br>4. 本版要变更记录、导入导出；已出数明细不回刷（消费侧细则见【转运装载率奖励（PDA）】、【转运装载率奖励报表】、【PDA装车进度及超载提示】）。|

# 四、需求分析

## 4\.1 需求价值

|**版本**|**需求价值**|
|---|---|
|V1\.0\.0|减少总部转运1人每天一半时间计算体积装载率奖励。|
|V3\.0\.0|1. 方案维护更精细、节省不必要车线成本。<br>2. 方案制定更准确、员工装载率更公平减少极端奖励车线出现频次。<br>3. 方案调整更灵动便捷、顺应公司发展需要随时可以调整方案。<br>4. 方案制度更完善漏洞更少、有利于培养员工和管理人员的信任感。|
|V4\.0\.0|1. **超载考核可例外配置**：高速不限重等场景可线上维护白名单，减少误扣装载率奖励与线下补差。<br>2. **装车提示可同源例外**：命中同一配置后分拨装车不再弹超载相关提示/拦截，与算奖白名单一致可控。<br>3. **任务类型可拆开配**：无汽运任务与自有/外请分开维护，网点方向用车线下一站表达，避免「全部」一刀切。<br>4. **配置可追溯**：独立变更记录与导入导出，便于总部/有权限人员维护与审计。|
