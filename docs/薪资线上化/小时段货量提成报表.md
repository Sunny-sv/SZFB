## 5.4 需求描述

### V1.0.0

**菜单路径：** 数智分拨 → 货量提成 → 薪资线上化 → 小时段货量提成报表。

**数据排序（正式查询、测算结果共用）：**

|维度|排序|
|---|---|
|分拨维度|分拨中心首字母升序|
|人员维度|分拨中心首字母升序，同人按人事工号升序，同人同人事工号再按岗位|

同页用「查询模式」在正式查询、测算结果之间切换；两种模式规则分节如下，互不混写。

---

#### 正式查询

**操作提示语：** 无数据「暂无数据」；导出成功「导出成功」。

**进数与人员范围（五业务线共用）：**

1. **货量：**取对应操作货量（吨；移动另含托数），按**子单扫描时间**归到小时段（`H点`=`H:00:00`～`H:59:59`）。**取数口径与【交接单人员提成】一致**（本职适用岗位操作货量）；**不含**流水线移动；**不含**「8 吨以上大票」拆分口径（该大票后续独立核算上线后，装卸等普货侧不再含其货量，本报表跟同期【交接单人员提成】口径走）。
2. **业务日列序：** 15→…→23→0→…→14。
3. **不统计：** 外包、支援一律不统计。仅下列适用岗位纳入统计；不在适用岗位内的视为兼职，不统计（流水线直装无兼职概念，仍排除外包、支援）。**适用岗位（与【小时段加减单价维护】相同）：**<br>    1. 装卸：岗位＝装卸工、装卸组长<br>    2. 移动：岗位＝电叉司机、叉车组长、机叉司机<br>    3. 流水线卸货：岗位＝L卸货员、L卸货组长<br>    4. 流水线码货：岗位＝L码货员、L码货组长<br>    5. 流水线直装：有操作均统计（仅限武职岗，仍排除外包、支援）

**加减（方案取值逻辑）：**

对每一票有货量的子单，先定操作类型，再取该小时该类型的加减：

1. 先根据「分拨中心 + 人事工号 + 业务线 + 操作类型」取【小时段加减单价维护】**员工方案**：状态为待生效 / 生效中 / 已失效，且有效期限包含该子单扫描日所在自然月。<br>    1. 操作类型匹配顺序：先匹配方案已选**专属操作类型**含该子单操作类型的；未命中再匹配操作类型为「全部」的员工方案。<br>    2. 命中后：取该方案区间展开后对应小时的加减；未覆盖小时为 0。不再取分拨方案。
2. 未命中员工方案时，根据「分拨中心 + 业务线 + 操作类型」取【小时段加减单价维护】**分拨方案**：状态、有效期限、不认状态、多条优先级同上。<br>    1. 操作类型匹配顺序同上：先专属、再「全部」。<br>    2. 命中后：取该方案区间展开后对应小时的加减；未覆盖小时为 0。
3. 员工方案、分拨方案都未命中 → 该小时加减按 0。

**提成：** 展示与导出截取 **4 位小数**。

|人员|人员组件|1. 支持多选；仅适用岗位人员（见上文「进数与人员范围」）。<br>2. 默认值：**空，不参与过滤。**<br>3. 查询逻辑：选中内容包含人员。|

###### 数据列表

**二级 Tab：** 分拨维度（默认）、人员维度。

**关系：** 先按**人员维度**算到「人 + 岗位」；**分拨维度＝同一分拨下这些行对应字段之和**（若查询条件选了人员/岗位，只汇总符合条件的行）。

**单位说明（列表上方）：** 货量单位：吨；提成单位：元（保留 4 位小数）。

**时段加减：**按上述「加减（方案取值逻辑）」。

**人员维度**

**一行：**一个人一个岗位。汇总列始终显示，且按日期范围内**全部小时段**合计，**不随「显示小时段」变化**；各小时段列只展开「显示小时段」已选的（业务日 15～14）。

|字段|取值逻辑|
|---|---|
|分拨中心|该人该岗位操作所在分拨。|
|员工姓名|员工姓名。|
|人事工号|人事工号。|
|岗位|本行岗位（适用岗位范围内；同一人多岗位则多行）。|
|汇总 · 操作货量（不拆分）|该人该岗位、查询日期内**全部小时段**、本业务线操作货量合计（吨）；按子单扫描时间；扫描日落在日期内。查了操作类型则只含该类型。不随「显示小时段」变。|
|汇总 · 货量（拆分 · 某类型）|同上（全部小时段，不随「显示小时段」变），且操作类型＝该列类型（网点装车 / 干线装车 / 网点卸车 / 干线卸车）。|
|汇总 · 提成|该人该岗位日期范围内全部小时段：各子单货量 × 对应小时对应类型加减，加总（可为负）；不随「显示小时段」变。不拆分＝各类型提成之和；拆分＝该类型提成之和。|
|各小时 · 操作货量 / 某类型货量|扫描时间在该 `H点`（H:00:00～H:59:59）且在日期范围内的该人该岗位操作货量。拆分时再按类型拆。各已选小时规则相同，不逐列写。|
|各小时 · 提成|该小时该人该岗位货量 × 该小时该类型加减，加总。|

**分拨维度**

**一行：**一个分拨。汇总列始终显示，且按全部小时段合计、不随「显示小时段」变；各小时段列规则同人员维度。

|字段|取值逻辑|
|---|---|
|分拨中心|该分拨。|
|汇总 · 操作货量 / 拆分各类型货量|＝该分拨下人员维度对应货量字段之和。|
|汇总 · 提成|＝该分拨下人员维度「提成」之和。|
|各小时 · 货量 / 提成|＝该分拨下人员维度同一小时对应字段之和。|

**双击：**双击某一行 → 切到人员维度，只看该分拨下的「人 + 岗位」行（写入查询条件「分拨中心」；其他条件保留）。

#### 测算结果

**入口：**

1. **有明细须从维护进入：**测算明细**只能**从【小时段加减单价维护】「查看测算」（顶部或行内）带任务进入；进入后查询模式＝**测算结果（只读）**，展示该次测算明细与测算说明条。测算模式**不留**分拨/人员/岗位/日期/操作类型及查询、重置，不可在本页改条件现算测算。
2. **本页切换：**可把查询模式切到「测算结果」，但**不能**在本页单独发起测算查询。若当前没有维护带入的测算任务 → 列表无数据，列表区展示提示：`当前没有可查看的测算任务。请到【小时段加减单价维护】勾选一条已测算完成的方案，再点「查看测算」进入本页。`；不展示测算说明条。

**业务线 Tab：**可自由切换。有测算任务时：当前 Tab＝任务所属业务线 → 展示该次测算明细；切到其他业务线 → 列表无数据，列表区展示提示：`当前测算任务属于「{业务线}」，请切回该业务线查看，或返回维护重新选择方案。`（测算说明条仍可保留展示该次任务信息）。无测算任务时：各业务线均无明细，列表区按上文「本页切换」提示。

**进数与人员范围：**

1. **货量归小时段、业务日列序、外包/支援/兼职不统计、适用岗位：**与正式查询相同。
2. **人员范围差异：**<br>    1. **员工方案测算：**只统计该员工。<br>    2. **分拨方案测算：**统计该分拨适用岗位人员。

**加减取值：**与正式查询「加减（方案取值逻辑）」相同（操作类型先专属、再「全部」；取对应小时，未覆盖为 0）；方案固定为该次测算任务绑定的方案，不再按员工/分拨另行匹配。

**不进薪资：**测算结果**不进**【转运人员薪资】。

**提成（差额）小数：**与正式查询相同，截取 **4 位小数**。

##### 测算说明条

仅测算结果模式且**已有**维护带入的测算任务时，在列表上方展示。正式查询不展示；无测算任务时不展示。

|项|说明|
|---|---|
|标题|测算结果（只读）|
|测算方案|该次测算任务绑定方案的展示文案，与【小时段加减单价维护】测算弹框「方案」一致。<br>1. **分拨方案：**`萧山分拨中心 · 网点装车`（多个操作类型时顿号拼接）。<br>2. **员工方案：**`萧山分拨中心 · 起正成 / 00621257 · 网点装车`|
|分拨中心|该次测算任务绑定的分拨中心。|
|操作类型|该次测算任务绑定的操作类型（多个顿号拼接）。|
|测算日期段|该次测算任务填写的起止日期；展示带固定时分秒：开始日 **15:00:00**、结束日 **14:59:59**（只展示不改）。|
|本区间增减合计|该次测算在本页**人员维度**各行「汇总 · 测算提成」之和；保留 4 位小数；正数带「+」。与【小时段加减单价维护】列表「本区间增减合计」同口径。|
|人数|该次测算明细里有货量的人员去重个数；无货量不计。|
|员工姓名、人事工号|**仅员工方案**展示；该次测算绑定的员工。|
|底语文案|`本页展示该次测算结果，仅供查看。可切「正式查询」查正式数据，或点击「返回维护」返回维护页面。`|

##### 装卸

列表结构、二级 Tab、分拨/人员关系、展示方式与小时段筛选规则与正式查询「装卸」相同；以下只写测算差异。

###### 查询条件

|名称|控件|说明|
|---|---|---|
|查询模式|单选下拉框|1. 枚举：正式查询、测算结果（只读）。<br>2. 从维护「查看测算」进入时默认**测算结果（只读）**。<br>3. 无任务时切到测算结果 → 列表无数据并提示到维护进入；**不支持**在本页单独查测算。|
|展示方式|复选框|与正式查询相同；只改列展示，不重算测算任务。|
|显示小时段|小时段筛选组件|与正式查询相同。|

测算模式下：**隐藏**分拨中心、人员、岗位、日期、操作类型及查询、重置；保留查询模式、展示方式、显示小时段。

###### 按钮操作

|名称|说明|
|---|---|
|导出|1. 按当前可见列导出（含现行提成、测算提成）。<br>2. 文件名：`小时段货量提成报表_装卸_{分拨或人员维度}导出_{年月日时分秒}`。|
|返回维护|1. 仅测算结果模式展示。<br>2. 回到【小时段加减单价维护】；也可切回正式查询继续查数。|

###### 数据列表

**单位说明（列表上方）：** 货量单位：吨；提成单位：元（保留 4 位小数）。单位说明下方为**测算说明条**。

**时段加减：**按上述测算「加减取值」。

**人员维度**

**一行、汇总列与小时段列展开规则：**与正式查询相同。货量/提成按该次**测算日期段**汇总（说明条展示日期段；列表**无「日期」列**）。

|字段|取值逻辑|
|---|---|
|分拨中心 / 员工姓名 / 人事工号 / 岗位|与正式查询相同。|
|汇总 · 操作货量 / 拆分各类型货量|与正式查询相同（日期按测算日期段；操作类型按该次测算绑定类型范围）。不随「显示小时段」变。|
|汇总 · 现行提成|同一批该人该岗位货量（全部小时段），按测算日期段内这些人**实际会用的正式小时段方案**算出的提成合计（无命中则 0）；与【交接单人员提成】一口价无关。不随「显示小时段」变。|
|汇总 · 测算提成|同一批该人该岗位货量（全部小时段），按本条测算绑定的**小时段方案**算出的提成合计；不随「显示小时段」变。|
|各小时 · 操作货量 / 某类型货量|与正式查询相同（日期按测算日期段）。|
|各小时 · 现行提成|该小时该人该岗位货量，按测算日期段内实际会用的正式小时段方案算出的提成；没有为 0。|
|各小时 · 测算提成|该小时该人该岗位货量，按本条测算绑定小时段方案算出的提成。|

**分拨维度**

|字段|取值逻辑|
|---|---|
|分拨中心|同人员维度。|
|汇总 · 操作货量 / 拆分各类型货量|＝该分拨下人员维度对应货量字段之和。|
|汇总 · 现行提成 / 测算提成|＝该分拨下人员维度对应提成字段之和。|
|各小时 · 货量 / 现行提成 / 测算提成|＝该分拨下人员维度同一小时对应字段之和。|

**双击：**双击某一行 → 切到人员维度，只看该分拨下的「人 + 岗位」行（仅在本测算结果内筛该分拨；其他展示条件保留）。

#### 验收要点

|序号|验收要点|
|---|---|
|1|菜单：数智分拨 → 货量提成 → 薪资线上化 → 小时段货量提成报表。|
|2|测算明细须从【小时段加减单价维护】「查看测算」带任务进入；本页无任务切到测算结果时仅空列表提示，不支持单独查测算；可返回维护；测算模式业务线 Tab 可切换，非任务所属业务线时列表空并提示切回。|
|3|五业务线 × 分拨/人员维度；列表**无「日期」列**；分拨维度双击下钻人员维度（正式写入分拨条件；测算仅在本结果内筛该分拨）。|
|4|展示方式默认汇总，勾选后按类型拆分；小时段默认 15～14；汇总列始终显示且为全部小时段合计（不随「显示小时段」变）；测算时另展示现行提成、测算提成（均为小时段方案，非交接一口价）；列序业务日 15→14。|
|5|正式查询日期默认当前自然月 1 号～最后一天；业务日跨天选日有提示。|
|6|货量口径与【交接单人员提成】一致；外包/支援/兼职不统计；不含流水线移动、不含 8 吨以上大票拆分口径；正式加减认待生效/生效中/已失效且有效期盖住扫描月；测算加减用绑定方案且不进薪资；员工方案测算仅本人。|
|7|提成/差额/本区间增减合计保留 4 位小数。|
|8|导出文件名含报表名、业务线、维度、时间戳。|
|9|组织适用范围为五类分拨全部。|
