## 5.4 需求描述

### V1.0.0

**菜单路径：** 薪资相关 → 移动自动合托特殊提成报表（最终路径实施时对齐现网）。

**数据排序：**

|Tab|排序|
|---|---|
|分拨汇总|按分拨中心首字母升序|
|人员汇总|按分拨中心首字母升序|
|子托明细|按移动时间降序|

**操作提示语：** 查询无数据提示「暂无数据」；导出成功提示「导出成功」；失败提示具体原因。

**全局进数（三 Tab 共用）：**

1. 仅同时满足：子托有 **移动自动合托** 标识 + 子托移动自动合托类型 = **专项合托**。  
（专项合托仅自有+武职经打标全流程可能产生；外包/非武职打标固定为常规合托，故不会进本报表。）  
2. **不进**：移动自动合托类型 = **常规合托**的子托（含外包、非武职打标固定为常规合托的部分）。  
3. **武职判定 / 岗位时点：** 打标侧已处理；本报表只读「专项合托」结果。  
4. **薪资月**：某月（记为 M 月）时间窗为 **M 月 1 日 15:00:00 ～ 次月 1 日 14:59:59**；子托按**移动时间**落在哪一窗归属哪一薪资月。查询条件「月份」选单月，过滤该薪资月整窗。  
5. **操作类型**（网点卸车移动 / 干线卸车移动）：取【移动作业统计】同名字段，本报表不另造判定。  
6. **提成金额**：按【移动自动合托提成方案维护】适用分拨上的**特殊提成单价**，结合子托操作类型（网点卸车移动 / 干线卸车移动）及维护页计价方式计算；分拨/人员汇总 = 下属子托提成金额之和。转运人员薪资取本报表结果，不另算。

#### 分拨汇总

按操作分拨汇总特殊合托货量与提成；**双击整行**下钻至人员汇总。

##### 查询条件

|名称|控件|说明|
|---|---|---|
|分拨中心|文本输入框|1. 默认值：空，不参与过滤。<br>2. 查询逻辑：操作分拨名称包含输入内容。|
|月份|月份选择器|1. 只能选单月，不可跨月、不可选日时分秒。<br>2. 默认值：**当前薪资月**（按当天落入的薪资月，非日历自然月 0 点～月底）。<br>3. 查询逻辑：子托移动时间所属薪资月 = 所选月份。|

本 Tab 无：操作环节、是否支援、托状态。
