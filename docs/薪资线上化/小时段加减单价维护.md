#### 全局约定

|**项**|**规则**|
|---|---|
|页面结构|主 Tab：装卸、移动、流水线卸货、流水线码货、流水线直装。每个主 Tab 下子 Tab：**分拨方案**、**员工方案**。|
|有效期限|区间月份选择器：有效开始月份～有效结束月份（**不选到日**）。命中算差额：子单扫描日所属**自然月**落在起止月（含）内。|
|状态|1. **待提交：**已保存，尚未点「提交确认」（含：新增保存；已驳回后再次编辑保存成功）。<br>2. **待确认：**分拨已提交，等总部确认/驳回。<br>3. **已驳回：**总部驳回；意见留在列表。分拨（或总部）编辑并**保存成功后 → 自动变为待提交**，再走提交确认。<br>4. **待生效：**已通过确认，有效开始月份晚于当前自然月。<br>5. **生效中：**已通过确认，且有效期限包含当前自然月。<br>6. **已失效：**结束月份早于当前自然月。|
|状态自动切换|待生效→生效中、生效中→已失效：按自然月与有效期限自动判断。|
|适用岗位|仅下列本职岗位参与时段加减；外包、支援一律不参与。不在适用岗位内的人（兼职）不进测算摘要人数、也不进【小时段货量提成报表】。<br><br>1. **装卸：**岗位＝装卸工、装卸组长。<br>2. **移动：**岗位＝电叉司机、叉车组长、机叉司机。<br>3. **流水线卸货：**岗位＝L卸货员、L卸货组长。<br>4. **流水线码货：**岗位＝L码货员、L码货组长。<br>5. **流水线直装：**有操作均参与（**无兼职概念**）；仍排除外包、支援。|
|操作类型|1. 维护可选「全部」或该业务线专属操作类型。**专属操作类型可多选**（同一套加减）；**「全部」与专属操作类型互斥**，不可同选。「全部」是兜底方案，不是把所有专属勾满。<br>2. 匹配算差额：专属 → 全部 → 加减按 0。<br>3. **可选项：**<br>    1. **装卸：**全部；网点装车、干线装车、网点卸车、干线卸车。<br>    2. **移动：**全部；网点移动、干线移动。<br>    3. **流水线卸货：**全部；网点卸货、干线卸货。<br>    4. **流水线码货：**全部；网点码货、干线码货。<br>    5. **流水线直装：**全部；网点直装、干线直装。|
|加减录入|按区间行维护，规则如下：<br>1. 每行：开始小时～结束小时 + 加减金额；业务日序 **15～14**。<br>2. **允许多段**。<br>3. **允许跨零点**（如 22～1）。<br>4. **未覆盖小时按 0**。<br>5. 区间**不可重叠**且已占用小时不可再选。<br>6. **加减金额精度：**「加减（元/吨）」「加减（元/托）」均可正可负可为 0；最多 **2 位小数**（超过 2 位不可保存，提示精度超限）。<br>7. **移动：**同一套区间行上分列「加减（元/吨）」「加减（元/托）」；只调其一另一列填 0；差额＝吨差额＋托差额。<br>8. 其他业务线仅「加减（元/吨）」。|
|测算|1. 按钮名：**测算**。须先有方案；**仅待提交**可测算；异步排队；列表展示该行测算摘要。<br>2. 加减取勾选方案已保存的时段加减，测算弹框**不改**加减；测算日期段**不限制**须落在有效期限内。<br>3. **测算范围：**<br>    1. **分拨方案：**本方案分拨中心 + 已选操作类型；适用岗位本职；外包/支援/兼职不进。<br>    2. **员工方案：**仅该员工（人事工号）+ 本方案分拨中心 + 已选操作类型；适用岗位本职；外包/支援/兼职不进。<br>4. 分拨「提交确认」须本行测算已完成；总部「保存并生效」可不测算。<br>5. 明细仅能从本页「查看测算」进入【小时段货量提成报表】测算结果模式查看（取本条方案最近一次已完成测算）。|
|上月补录窗口|1. **系统参数：**上月方案维护截止日（自然日，默认 **6**；可配置）。<br>2. **窗口内：**当前自然月的日期 **不超过**该参数时，视为处于「上月补录窗口」。<br>3. **窗口内额外放开：**<br>    1. **新增：**有效开始月份最早可选**上月**（否则最早为当月）。<br>    2. **编辑：**窗口内，**仅总部**可编生效中/已失效且开始月=上月的方案（另见「编辑严控」）；分拨不能编已确认通过的方案。<br>    3. **删除：**窗口内，**仅总部**可删生效中/已失效且开始月=上月的方案（另见「删除严控」）。<br>    4. **截断结束月（为上月腾空档）：**见下「有效结束月份下限」——窗口内允许把长周期方案结束月最早改到**前两个月**，避免与补录的上月方案撞期。<br>    5. **提交确认 / 确认生效 / 总部保存并生效：**开始月＝上月的方案**允许**走完生效（与新增能选上月一致）。<br>4. **窗口外：**<br>    1. 不得新增开始月＝上月的方案；结束月下限见下（最早改到**上个月**）。<br>    2. 开始月＝上月的方案：**不得**提交确认、确认生效、总部保存并生效。须先驳回，把开始月改为**当月**（或更晚）后再提。<br>    3. **举例（截止日＝6）：**9 月 1～6 日，开始月＝8 月可以确认生效；9 月 7 日起，开始月＝8 月的待确认方案不能确认生效。|
|有效结束月份下限（编辑时）|改有效结束月份时，须**同时**满足：<br>1. **不得早于有效开始月份。**<br>2. **最早可改到的月份（补录腾空档）：**<br>    1. **上月补录窗口内：**最早可改为**前两个月**（例：当月=8 月，最早可改为 6 月）。<br>    2. **不在窗口内：**最早可改为**上个月**（例：当月=8 月，最早可改为 7 月）。<br>3. **举例（当月=8 月，窗口内）：**旧方案有效期 1 月～12 月，要补录 7 月新方案时，先把旧方案结束月改为 6 月，再新增开始月=7 月的方案；若结束月仍不得早于当月，则无法腾出 7 月，补录必然撞期。|
|编辑严控|1. **谁能编（先看角色）：**<br>    1. **分拨：**只能编**待提交、已驳回**。总部已确认通过的（**待生效、生效中、已失效**）分拨**不能编**——否则待生效时改加减等于绕过总部审核。<br>    2. **总部：**待提交、已驳回可编；**待生效、生效中、已失效**按下面字段规则编（受上月补录窗口约束）。<br>2. **待确认：**谁都不能编辑（只能总部确认生效或驳回）。<br>3. **总部编辑待生效：**可改全部字段（开始月不得早于「新增」允许的最早月；结束月按「有效结束月份下限」）。<br>4. **总部编辑生效中且开始月=当月：**可改全部字段；结束月按下限。<br>5. **总部编辑生效中且开始月=上月：**仅窗口内可改全部；窗口外仅可改结束月（按下限）。<br>6. **总部编辑生效中且开始月≠当月、≠上月（或上月但窗口外）：**仅可改有效结束月份；结束月按下限。<br>7. **总部编辑已失效：**默认不可编；窗口内且开始月=上月 → 可改全部字段；结束月按下限。<br>8. **分拨/总部编辑待提交、已驳回：**可改全部字段（开始月/结束月限制同新增与「有效结束月份下限」）；**已驳回保存成功 → 待提交**。<br>9. **保存后测算摘要：**<br>    1. **待提交 / 已驳回（保存后变待提交）：**若改了分拨中心、员工、操作类型、有效期限、时段加减中任一项 → **清空测算结果**（三列均为「-」），须重新测算后才能提交确认；**仅改备注** → 保留原测算。<br>    2. **待生效 / 生效中 / 已失效（总部编辑保存成功）：**若改了分拨中心、员工、操作类型、有效期限、时段加减中任一项 → **清空测算结果**（三列均为「-」）；**仅改备注** → 保留。|
|删除严控|1. **分拨**可删：待提交、待确认、已驳回。<br>2. **总部**可删：①待提交/待确认/已驳回；或②待生效；或③生效中且开始月=当月；或④生效中/已失效且开始月=上月且在上月补录窗口。<br>3. 其余置灰。|
|撞期|同一「分拨（+员工方案时的员工）+ 业务线 + 某一操作类型」与已有**待提交、待确认、待生效、生效中、已失效**方案有效月有交集 → **禁止保存 / 禁止确认生效**，提示与已有方案重复（或有效期交叉）；**不做自动截断**旧方案。一条方案勾多个专属操作类型时，**每个操作类型分别**校验。|
|变更记录|不做|
|OA|不做|

|名称|说明|
|---|---|
|新增|1. 单击打开新增弹框；标题含业务线与「分拨方案/员工方案」。<br>2. **弹框字段**<br>    1. **分拨中心：**控件：数据权限组件，单选；必填。<br>    2. **员工：**仅员工方案展示；控件：人员组件，单选；必填；可选本分拨人员。<br>    3. **操作类型：**控件：复选框组；选项：全部 + 专属操作类型；默认勾选第一个专属操作类型；必填至少 1 项。勾「全部」清空专属；勾任一专属取消「全部」。<br>    4. **有效开始月份 / 有效结束月份：**控件：月份选择器；必填；开始月不得早于当月（窗口内不得早于上月）；结束月不得早于开始月。<br>    5. **备注：**文本输入框；非必填；最多 200 字。<br>    6. **时段加减：**区间表。列：开始、结束、加减（元/吨）［移动另加加减（元/托）］、操作。按钮「新增区间」。规则按全局「加减录入」（加减金额最多 **2 位小数**）。<br>3. **按钮：**取消；保存（待提交）；总部另可「保存并生效」（不强制测算）→ 待生效或生效中；是否允许按全局「上月补录窗口」。<br>4. **确定/保存校验：**<br>    1. 不符合字段规则 → 不保存，按字段提示。<br>    2. 符合 → 唯一性：按分拨（+员工）+ 业务线 + 各已选操作类型，与待提交/待确认/待生效/生效中/**已失效**方案有效月是否有交集。<br>        1. 无交集 → 保存成功。<br>        2. 有交集 → **不保存**，提示与已有方案重复（有效期交叉）。|
|编辑|1. 仅选中单条；可编条件按全局「编辑严控」（含分拨/总部角色）；不可编置灰。<br>2. 分拨点到待生效/生效中/已失效时提示：已确认通过的方案仅总部可编辑。<br>3. 未选单条提示：请选中单条数据后再编辑。<br>4. 弹框同新增；仅可改结束月时其余置灰，提示：当前方案仅可修改有效结束月份。<br>5. 保存校验同新增（撞期禁止保存，不截断；含已失效）。<br>6. **当前为已驳回：**保存成功后状态**自动变为待提交**（原驳回意见仍保留在列表，可对照修改）。<br>7. **测算摘要：**保存成功后按全局「编辑严控」第 9 点处理（关键字段变更清空测算；仅改备注保留）。|
|查看详情|1. **仅列表行内「查看详情」**（所有状态均可点）；不做行内编辑、不做单独「查看加减」。<br>2. 只读展示：分拨中心、员工姓名、人事工号（员工方案）、操作类型、有效期限、状态、备注、**时段加减区间表**、测算摘要（本区间增减合计/人数/测算日期段，规则同列表）、创建/修改/确认信息与意见。<br>3. 详情内可提供「查看测算」（须有已完成测算，查询逻辑同顶部「查看测算」）。确认生效、驳回用顶部按钮。|
|删除|1. 可删条件按「删除严控」；含不可删行则提示并中止。<br>2. 确认弹框文案：`确认删除该方案？删除后不可恢复。（共X条）`；按钮：取消 / 确认。|
|提交确认|1. **仅分拨**；仅状态＝待提交且测算已完成（测算结果三列非「-」、且非测算中）。<br>2. 未测算/测算中/测算已被清空提示先点「测算」。<br>3. 是否允许按全局「上月补录窗口」（窗口外且开始月＝上月 → 不能提交）。<br>4. 确认弹框：展示分拨、操作类型、有效期限、本区间增减合计；备注选填；确认后 → 待确认，并固化测算摘要。|
|确认生效|1. **仅总部**；仅待确认。<br>2. 是否允许按全局「上月补录窗口」（窗口外且开始月＝上月 → 不能确认，须驳回后改开始月）。<br>3. 撞期按全局「撞期」再校验一次（含已失效）；有交叉 → 不能确认，提示重复。<br>4. 弹框：意见选填；确认后按有效期限落入待生效或生效中。|
|驳回|1. **仅总部**；仅待确认。<br>2. 弹框：意见必填；确认后 → **已驳回**（意见写入列表）。<br>3. 之后：分拨或总部打开编辑并**保存成功 → 状态自动变为待提交**；若改了关键字段须再「测算」再「提交确认」（仅改备注且原测算仍在则可直接提交确认）。|
|测算|1. 须勾选单条；**仅待提交**可测算；测算中不可再点。<br>2. **弹框**<br>    1. **方案：**只读；按勾选方案带出分拨中心、操作类型；员工方案另带员工姓名、人事工号。展示示例：<br>        1. **分拨方案：**`萧山分拨中心 · 网点装车`（多个操作类型时顿号拼接，如 `萧山分拨中心 · 网点装车、干线装车`）<br>        2. **员工方案：**`萧山分拨中心 · 起正成 / 00621257 · 网点装车`<br>    2. **测算日期段：**区间日期；必填；**不要求**落在方案有效期限内。<br>3. 加减取本条方案已保存内容，弹框不改加减。<br>4. 测算范围按全局「测算」；确定后异步测算；结果写入该行测算结果列。|
|查看测算|1. 须勾选单条方案。<br>2. **能否打开：**<br>    1. 本行测算结果已完成（测算结果三列有正式结果）→ 可点，进入报表看明细。<br>    2. 本行从未测算，或测算已被清空（三列均为「-」）→ 不可进，提示：`请先对该方案点「测算」，测算完成后再查看。`<br>    3. 本行正在测算中（本区间增减合计＝「测算中」）→ 不可进，提示：`测算进行中，请稍后再查看。`<br>3. 打开【小时段货量提成报表】，查询逻辑如下（页面展示以报表 PRD 为准，此处不重复）：<br>    1. 查询模式＝**测算结果（只读）**。<br>    2. 打开与本条方案相同的**业务线 Tab**（可再切其他业务线；非本任务所属业务线时列表空并提示切回，规则以报表 PRD 为准）。<br>    3. 取数＝本条方案**最近一次已完成的测算任务**（分拨中心、操作类型、测算日期段、加减以该任务绑定为准）；不是正式方案现算。<br>    4. 列表范围：该测算任务结果内人员货量与时段差额（分拨方案＝该分拨适用人员；员工方案＝仅该员工）；外包/支援/兼职不进。<br>    5. 小时段、展示方式（汇总/按操作类型拆分）、分拨维度/人员维度及分拨双击下钻：按报表页当前条件与规则过滤、展示该次测算结果。|
|导出|按当前查询条件导出列表字段；文件名：`小时段加减单价维护_{业务线}_{分拨或员工方案}导出_{年月日时分秒}`。|

|业务线|专属操作类型|加减列|

#### 验收要点

|序号|验收要点|
|---|---|
|1|菜单路径：数智分拨 → 货量提成 → 薪资线上化 → 小时段加减单价维护；五业务线 × 分拨/员工方案可切换。|
|2|操作类型：专属可多选；全部与专属操作类型互斥；列表顿号展示。|
|3|有效期限按月；加减按区间维护，金额最多 3 位小数；移动同表吨/托两列。|
|4|仅待提交可测算（须先维护方案）；员工方案测算仅本人；分拨提交确认须已测算；改加减/操作类型/有效期/员工/分拨清空测算，仅改备注保留；总部可自维保存并生效且不强制测算；生效后改关键字段亦清空测算摘要。|
|5|分拨只能编待提交/已驳回；已驳回保存成功自动变待提交；待生效及之后仅总部可编；待确认谁都不能编。|
|6|上月补录窗口外：开始月＝上月的方案不得提交确认、确认生效、保存并生效。|
|7|撞期：与待提交/待确认/待生效/生效中/**已失效**有效月交叉均禁止保存/确认生效，不做自动截断。|
|8|删除确认文案含「共X条」；无变更记录入口；**无导入、无下载模板**。|
|9|组织适用范围为五类分拨全部；功能权限无权限时按钮不展示。|
|10|测算明细须从本页「查看测算」进入报表；测算日期段不限制须落在有效期限内。|
