工作规划

智能排班

下阶段重点规划

适用：直营分拨中心、服务站。先摸清人为怎么排班，再决定系统做到哪一层；不做装车码放，首期不做派到哪辆车。

WHY · 为什么做

把经验排班变成可对齐的班次安排

  • 货量按小时波动，靠经验排班，容易人等多 / 货等人 / 忙闲不均
  • 请假、旷工后补人靠口头，难追踪
  • 目标：更稳地决定「谁上哪个班、哪类岗」；补位可追踪
  • 与【转运人员排班维护】分开：那边管考勤规则，这边管预测驱动编制
HOW · 怎么推进

先现状，后系统

  • 跟完一个试点仓的完整排班周期
  • 画出人为作业图（不先画引擎）
  • 对齐首痛：班前人数 / 班中补人（车级后置）
  • 规则清楚后：建议名单 + 调度确认发布

NEED · 需要支持

请领导拍板

  • 试点仓白名单（建议先 1 个）
  • 适用环节：卸 / 装 / 移哪个先
  • 现场调度对接人 + 固定联调窗口
  • 预测源、人员、考勤只读授权
  • MVP 未准出前：不并行全开、不强上车级指派
三句话：先摸清人怎么排 → 先班次名单，再车级 → 算法只建议，调度确认 倒班：需间隔时空一个自然日，只提示；外包另定
