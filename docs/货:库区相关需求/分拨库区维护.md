# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V2\.0\.0|**无效倒货规模大、成本高**：2026 年 2 月全国双库分拨无效倒货数据显示，仅卸车环节货量达 3271\.21 吨，全流程产生装卸货量 6546\.43 吨、移动货量 3271\.21 吨；按货量较大分拨平均装卸单价 11 元 / 吨，装卸成本增加约 7\.2 万元；移动单价 2\.4 元 / 吨，移动成本增加约 0\.8 万元（不含托成本），显著推高运营成本。<br>**运营时效提升：**倒货货物经过装卸移环节后增加运营时效。|
|V4\.0\.0|双库分拨下，网点交件与分拨/集配站交件的应交库区经常不一样，但系统只有一套「目的分拨 → 库区」配置。例如石家庄：网点交来目的为石家庄的应进到达库，目的为梅河口集配站的应可进出发库；而分拨/集配站来货仍按原大范围目的进库。两套诉求揉在同一配置里，网点面单库区、自动分库、混卸判断都会跟着错。且不是下属所有网点都要走新规则，需要按开单网点区分。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V2\.0\.0|- 双库分拨无效倒货导致增加运营成本；<br>- 希望系统自动校验货物应去库区与当前卸库区是否一致，不一致时需主管审核后才能卸车，从源头拦截无效倒货；<br>- 同时需生成倒货全流程操作报表，用于成本核算、问题追溯及流程优化。|
|V4\.0\.0|- 现有分拨/集配站交件的库区配置继续用通用配置。<br>- 网点交件按开单网点做特殊映射，不是所有网点都要配。<br>- 集配站来货与网点来货要能分开开关混卸；混卸开关只放在通用配置，用枚举区分，不挂在网点特殊上（避免无特殊网点时无处可配）。<br>- 特殊网点要「应去仍是 A、标识仍是 A，但可在 B 库卸」时，在网点特殊行上维护**额外可卸库区**；通用上的「额外可卸分拨」仍给未命中特殊的子单用。<br>- 开单、卸车、自动分库统一按子单开单网点是否命中网点特殊来分流。|

### V4\.0\.0

#### 页面结构

1. 同页增加两个 Tab：**通用配置**、**网点特殊配置**。
2. **通用配置**：承接本页 V3 及以前能力（库区主数据）；本版将该 Tab 的**库区**视为网点特殊的主数据。主数据跟库字段变更由网点特殊联查实时反映；主数据删除时同库特殊配置一并删除。本版另改「是否混卸限制」枚举（见下）。
3. **网点特殊配置**：新建「开单网点 + 目的 → 应交库区」映射；可选填**额外可卸库区**。库区必须选自通用配置有效库区；跟库字段从主数据带出、本 Tab 不可改。本 Tab **不维护**「是否混卸限制」。

#### 通用配置 · 是否混卸限制

字段名不变，仍按**所属分拨**同步（同分拨同值）。可选项由「是 / 否」改为：

| 选项 | 含义 |
|---|---|
| **否** | 集配站/分拨交件、网点交件都不做混卸拦截 |
| **全部** | 两类都做混卸拦截（对应原「是」） |
| **仅集配站交件** | 只对集配站/分拨交件做混卸拦截 |
| **仅网点交件** | 只对网点交件做混卸拦截 |

1. 新增/编辑/导入：必填；选项为上表四档。默认值：按所属分拨查通用配置已维护数据，有则带出，无则空。
2. 保存后：按所属分拨匹配通用配置已维护数据，若「是否混卸限制」与本次不一致，将同分拨已维护数据的该字段更新为本次值。
3. 查询条件：枚举为全部（不限）、否、全部、仅集配站交件、仅网点交件；默认全部（不限）。
4. 列表展示四档文案。
5. **历史数据**：原「是」→「全部」；原「否」→「否」。

说明：交接单如何归到「集配站/分拨交件」或「网点交件」，由各消费方 PRD 写清（如双库混卸提示）。

#### 库区主数据与网点特殊映射

**通用配置 = 库区主数据**：分拨物理库区、目的分拨中心、额外可卸分拨、WIFI/IP、是否混卸限制等在此维护。网点特殊只存映射与本 Tab 可维护字段；跟库字段（含状态）**不落网点侧可改副本**，列表与弹框按「所属分拨 + 库区」联查通用配置**实时展示**。

**网点特殊选库规则：**

1. 必须先选所属分拨，再选库区。
2. 库区下拉仅展示该所属分拨在「通用配置」中状态为**有效**的库区；失效或不存在则不可选。导入时库区须在通用配置中为有效，否则该行失败。
3. 选中库区后，下列字段从通用配置对应数据**自动带出，置灰不可编辑**（列表按主数据实时展示）：

|从主数据带出、网点特殊不可改|
|---|
|库区类型|
|库区标识|
|地址、经纬度、打卡距离(m)、模型地址|
|IP地址开始号段、IP地址结束号段、WIFI定库区|
|是否虚拟分库|
|状态|

**主数据删除联动：**

通用配置**删除**某「所属分拨 + 库区」后：网点特殊中同一所属分拨、同一库区的全部数据**一并删除**。网点特殊侧单独删除只删本 Tab 勾选行，不影响通用配置。本 Tab 不可单独改状态（状态跟主数据联查展示）。

**网点特殊可自行维护：**

|字段|说明|
|---|---|
|开单网点|必填，多选|
|目的分拨中心|必填，多选；可填分拨中心、集配站。同一行内多个目的须与本行「库区 + 额外可卸库区」规则一致；规则不同须拆多行（见列表说明）|

#### 验收要点

1. 同页可见「通用配置」「网点特殊配置」两 Tab，且权限可分开控制。
2. 网点特殊库区只能选通用配置中的**有效**库区；主数据带出字段不可改；列表主数据字段实时跟主数据。
3. 开单网点、目的分拨中心未填不可保存；目的分拨中心支持多选；额外可卸库区可不填。
4. 主数据跟库字段（含状态）变更后，网点特殊列表实时反映；主数据删除后，同库网点特殊配置一并删除。
5. 同一所属分拨下，任一「目的分拨中心 + 开单网点」组合不可与已有数据重复（含已失效数据）。
6. 通用配置「是否混卸限制」为四枚举；历史「是」变为「全部」；网点特殊无该字段。
7. 网点特殊列表可对同一开单网点、不同额外可卸规则拆成多行，目的多选同行展示。
