# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|网点无纸化交接在**发件扫描自动分库**时，仍按旧单套「目的 → 库区」取库。本分拨下属网点开单与干线/集配站应交库经常不一样（如石家庄网点目的不同库），自动分库会分错，后续交件、混卸跟着偏。|

## 5\.3 需求描述

### V1\.0\.0

本版只改 **网点无纸化交接** 发件扫描自动分库用的**库区**逻辑。

#### 发件扫描自动分库

|名称|说明|
|---|---|
|选表|1. 判断开单网点是否为**下一站分拨中心**的下属网点：<br>    1. 是 → 数据源 = 【分拨库区维护 - 网点库区配置】<br>    2. 否 → 数据源 = 【分拨库区维护 - 干线库区配置】<br>|
|取库区|1. 在已选数据源上，按**下一站分拨中心 + 子单目的分拨中心**匹配（状态 = 有效；）：<br>    1. 有维护：取对应**库区**，按该库区进行发件扫描自动分库<br>    2. 无维护：不取配置表库区做本次自动分库；|

**特殊说明**：本需求不考虑一点多交；一点多交网点开单仍匹配【干线库区配置】，不走【网点库区配置】。

#### 验收要点

|序号|验收要点|
|---|---|
|1|开单网点为下一站分拨中心下属网点 → 读网点库区配置取库区分库，不回退干线。|
|2|开单网点非下一站分拨中心下属 → 读干线库区配置取库区分库。|
|3|已选配置无维护对应目的 → 不按配置表库区自动分库，不回退另一套。|
|4|其它菜单 / 其它扫描类型的自动分库与改版前一致。|
