# 二、要解决的问题

|**版本**|**问题**|
|---|---|
|V1\.0\.0|**无效倒货规模大、成本高**：2026 年 2 月全国双库分拨无效倒货数据显示，仅卸车环节货量达 3271\.21 吨，全流程产生装卸货量 6546\.43 吨、移动货量 3271\.21 吨；按货量较大分拨平均装卸单价 11 元 / 吨，装卸成本增加约 7\.2 万元；移动单价 2\.4 元 / 吨，移动成本增加约 0\.8 万元（不含托成本），显著推高运营成本。<br>**运营时效提升：**倒货货物经过装卸移环节后增加运营时效。|
|V3\.0\.0|【分拨库区维护】已拆「通用配置」「网点特殊配置」，但本功能仍按旧单套配置取子单应去库区，网点交件应交库不准，混卸误判、漏判。例如石家庄：网点交件与集配站交件应交库不同，却共用一套目的匹配规则。|

# 三、业务分析

## 3\.1  用户调研

|**版本**|**调研结果**|
|---|---|
|V1\.0\.0|- 双库分拨无效倒货导致增加运营成本；<br>- 希望系统自动校验货物应去库区与当前卸库区是否一致，不一致时需主管审核后才能卸车，从源头拦截无效倒货；<br>- 同时需生成倒货全流程操作报表，用于成本核算、问题追溯及流程优化。|
|V3\.0\.0|- 网点交件应走「网点特殊配置」，集配站/分拨交件仍走「通用配置」。<br>- 混卸开关只在通用配置用四枚举区分集配站/网点；无特殊网点也能单独关网点混卸。<br>- 特殊网点要「应去 A、允许在 B 卸」时用特殊行的额外可卸库区；未命中特殊仍用通用额外可卸分拨。<br>- 子单应去库区按开单网点是否命中特殊分流；混卸开关按交接单维度整单生效。|

## 3\.2 产品方案

|**版本**|**方案**|
|---|---|
|V3\.0\.0|子单应去库区：先匹配网点特殊，命中直接取库区且不走猜库兜底；未命中走通用配置原规则（含兜底）。不一致放行：命中特殊看该行「额外可卸库区」是否含当前卸车库区；未命中看当前卸车库区在通用上的「额外可卸分拨」是否含目的。是否混卸限制：只读通用四枚举，按交接单归档为网点交件或集配站/分拨交件后判定。物理定库仍只读通用主数据。换库卸车、审核表、回单跳过等本版不改。|

#### 子单应去库区（子单维度）

用该子单的**开单网点**、**路由目的分拨**、操作分拨（所属分拨），在【分拨库区维护 - 网点特殊配置】中按「所属分拨 + 开单网点 + 目的分拨中心」匹配，且联查通用主数据后**状态 = 有效**：

1. **命中**：子单应去库区 = 该条配置的库区；
2. **未命中**：走下列通用规则。

**未命中网点特殊时，按通用配置取数：**

1. 优先确定**分拨库区数量**（根据操作分拨匹配【分拨库区维护 - 通用配置】中**状态 = 有效**的数据）。
2. 库区数量 = 2 个：
    1. 校验该分拨是否存在**状态 = 有效**且 **WIFI 定库区 = 是** 的记录：
        1. **存在**：按「当前分拨 + 路由目的分拨」匹配**有效**数据 → 有维护取对应库区；无维护则**任意库区卸车均视为混卸**（与改版前一致，本版不改该结果态后续处理）。
        2. **不存在**：按「当前分拨 + 路由目的分拨」匹配**有效**且**库区类型 = 到达库**的数据 → 有维护取到达库；无维护取出发库；若两条均为出发库取创建时间最早一条；若两条均为到达库且均无对应目的分拨则**任意库区卸车均视为混卸**（与改版前一致）。
3. 库区数量大于 2 个：按「当前分拨 + 路由目的分拨」匹配**有效**数据 → 有维护取对应库区；无维护则**任意库区卸车均视为混卸**（与改版前一致）。

#### 不一致时是否放行（额外可卸）

仅在本交接单已判定**需要执行混卸拦截**时判断。应去库区与当前卸车库区一致则正常卸车，不看额外可卸。

1. **命中网点特殊**（且联查状态有效）：看该特殊行「额外可卸库区」是否包含**当前卸车库区**。
    1. 包含：正常卸车扫描（应去/标识仍为特殊行库区）。
    2. 不包含或未维护：再走审核通过校验 / 弹双库混卸提示（与改版前一致）。
2. **未命中网点特殊**：看**当前卸车库区**在【分拨库区维护 - 通用配置】上的「额外可卸分拨」是否包含**子单目的分拨**。
    1. 包含：正常卸车扫描。
    2. 不包含：再走审核通过校验 / 弹双库混卸提示（与改版前一致）。

命中特殊时**不**再用通用「额外可卸分拨」给这票放行。

#### 是否混卸限制（交接单维度，只读通用配置）

**第一步：归档本交接单属于「网点交件」还是「集配站/分拨交件」**

| 场景 | 归档规则 |
|---|---|
| **无纸化卸车** | 上一站为**网点** → 网点交件 |
| **实时/项目卸车 · 有任务** | 上一站为**直营集配站**或**非直营集配站** → 集配站/分拨交件 |
| **无任务交接单**（无纸化、实时/项目均适用） | **不看上一站**；看该单**出库网点**类型：出库网点是**网点** → 网点交件；出库网点是**其他**（集配站/分拨等）→ 集配站/分拨交件；**出库网点为空或取不到类型** → **本单不执行混卸**（与未开混卸一致） |
| 其它上一站 | 不在混卸适用范围内，**不执行混卸** |

**第二步：读通用配置该操作分拨「是否混卸限制」（同分拨同值），判定本单是否拦截**

| 是否混卸限制 | 归为集配站/分拨交件 | 归为网点交件 |
|---|---|---|
| **否** | 不拦 | 不拦 |
| **全部** | 拦 | 拦 |
| **仅集配站交件** | 拦 | 不拦 |
| **仅网点交件** | 不拦 | 拦 |

**不拦**：本交接单整单不执行双库混卸拦截。**拦**：本单各子单（回单 H 开头等已有例外仍跳过）做应去库区与当前卸车库区比对，不一致再按「不一致时是否放行」判断。

#### 验收要点

|序号|验收要点|
|---|---|
|1|命中网点特殊且联查有效：应去取特殊库区，不跑通用猜库兜底；主数据改失效后视为未命中。|
|2|未命中网点特殊：应去与通用原规则一致（含兜底）；「任意库区均视为混卸」态与改版前一致。|
|3|无纸化：仅网点上一站或无任务进入混卸；实时/项目：直营/非直营集配站、网点或无任务进入混卸。|
|4|无任务看出库网点归档；出库网点为空或取不到类型 → 本单不执行混卸。|
|5|混卸四枚举：仅集配站交件、仅网点交件、全部、否 行为与维护页一致。|
|6|命中特殊：不一致看「额外可卸库区」；未命中：看当前卸车库区「额外可卸分拨」；物理定库仍只读通用。|
|7|换库卸车、审核表、回单跳过、前 N 件与改版前一致。|
